# 词族(Familia de palabras) — 一个词根,一串派生词

> **词族** = 同一词根(raíz/léxico)叠加不同后缀,派生出动词、名词、人物、形容词、抽象名词、指小/夸张/贬义等成串的词。掌握一个词根,同时解锁一族的词,记单词效率翻倍。
> 本文以 `estudio` 为完整范例,并列举尽可能多的高产词族。后缀规律汇总见文末。

---

## 九、后缀派生规律汇总

> 掌握这些常见后缀的含义,就能把"词根→一族词"串起来。

### 名词后缀

| 后缀 | 含义/用途 | 例 |
| --- | --- | --- |
| -ción / -sión | 动作、结果(抽象名词) | estudiar→estudio;educar→educación |
| -dad / -tad | 性质、状态 | claro→claridad;fuerte→fortaleza |
| -eza | 性质(常接形容词) | bello→belleza;dulce→dulzura |
| -ura | 性质、结果 | alto→altura;dulce→dulzura |
| -miento | 动作、结果 | sentir→sentimiento;pensar→pensamiento |
| -dor / -dora | 施动者、工具(人/物) | trabajar→trabajador;hablar→hablador |
| -ante / -ente | 施动者(人) | estudiar→estudiante;cantar→cantante |
| -ería | 场所、行业 | libro→librería;dulce→dulcería |
| -ero | 职业、容器 | libro→librero;casa→casero |
| -ito / -cito | 指小 | libro→librito;casa→casita |
| -ón / -ona | 夸张、大 | casa→caserón;comer→comilón |
| -ucha | 贬义 | casa→casucha |
| -ado | 集体、职位 | estudiante→estudiantado |

### 形容词后缀

| 后缀 | 含义 | 例 |
| --- | --- | --- |
| -oso / -osa | 充满…的 | trabajo→trabajoso;estudio→estudioso |
| -il | 属于…的 | estudiante→estudiantil |
| -ivo / -iva | 有…性质的 | acción→activo 等 |
| -able / -ible | 可…的 | leer→legible;comer→comestible |
| -al | 与…有关的 | nación→nacional |

### 动词后缀

| 后缀 | 含义 | 例 |
| --- | --- | --- |
| -ar(词根直转) | 由名词/形容词变动词 | estudio→estudiar;dulce→endulzar |
| -ecer | 使成为、变得 | fuerte→fortalecer;bello→embellecer |
| -izar | 使…化 | claro→clarificar;valor→valorizar |
| -ificar | 使成为 | claro→clarificar;fuerte→fortificar |

## 十、学习建议

1. **以词根为单位记忆**:看到一个词,先找它的词根,再想它的名词/动词/形容词兄弟。
2. **多查派生方向**:记住一个常用动词(如 estudiar),主动去查它的名词(estudio)、人物(estudiante)、形容词(estudiantil)形态。
3. **同时记"反义派生"**:如 escribir ↔ borrar, claro ↔ oscuro, vale 提醒——有些词族会跨前缀派生(des-hacer、sobre-vivir、re-leer)。
