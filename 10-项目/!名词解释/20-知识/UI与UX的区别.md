# UI 与 UX 的区别

> 同一个东西,两个人给出两句评价:「界面挺漂亮」和「用起来真费劲」。这两句评的不是同一件事 ——
> 前者评的是 **UI**(人和机器打交道的那个**面**),后者评的是 **UX**(从想干到干完的整段**经历**)。
> 本文讲清两个词的分界、各自能保证什么/保证不了什么,并用本机真实数字验证一次「界面好看」与「能用」的差别。
> **本文的固定写法**:每个概念按「**为解决什么痛点而生 / 一句话定义 / 大白话注解**」三段给出,再展开细节。
> 关联阅读:[CLI,TUI,GUI三种界面的区别](<CLI,TUI,GUI三种界面的区别.md>)、[CI-持续集成](<CI-持续集成.md>)。

## 一句话速览

| 名称 | 一句话定义 | 大白话注解 |
| --- | --- | --- |
| **UI(用户界面)** | 人与机器发生交互的那个**面**:看得见的控件、文字、色彩,与点下去之后的即时反馈 | 你眼睛看得到、手指点得到的那一层 |
| **UX(用户体验)** | 一个人**使用**某个产品 / 系统 / 服务的过程中产生的感知与反应 | 从「我想干这件事」到「我干完了」的整段经历 |
| **可用性(usability)** | UI 的一项质量属性:好不好学、好不好用、用着顺不顺 | UI 的体检项之一,不是 UX 的全部 |
| **可访问性(accessibility)** | 不同能力的人(色觉障碍、低视力、只用键盘)都能用同一套界面把事办成 | 把「能用」的门槛降到最低 |

---

## 一、两个词各指什么

### UI:人和机器打交道的那个面

> **为解决什么痛点而生**:机器内部的逻辑人看不见,人只能通过一个**约定好的表面**去操作它、读它的状态。没有这个面,操作无从谈起。
> **一句话定义**:在 HCI(人机交互)领域,UI 是**人与机器之间发生交互的那个空间**
> ([Wikipedia: User interface](https://en.wikipedia.org/wiki/User_interface));交互的目的,是让**人这端**能有效操作与控制机器,同时机器**回馈**有助于人判断的信息。
> **大白话注解**:UI 是驾驶舱 —— 方向盘、仪表盘、按钮。它可以是命令行、全屏文本界面或图形界面(三种形态见
> [CLI,TUI,GUI三种界面的区别](<CLI,TUI,GUI三种界面的区别.md>)),但都只是「面」。

### UX:用起来的整段经历

> **为解决什么痛点而生**:把一个界面做漂亮,用户照样可能办不成事 —— 关键数据不在库里、加载要等十秒、出错后不知道该点哪。
> 这些都不在「界面好看不好看」这一层,于是需要另一个词来指称「整段经历的品质」。
> **一句话定义**:UX 是**一个人与某个产品 / 系统 / 服务交互时的感受与反应**;国际标准 ISO 9241 的措辞是「由使用(或预期使用)一个系统、产品或服务而产生的**感知与反应**」
> ([Wikipedia: User experience](https://en.wikipedia.org/wiki/User_experience))。
> **大白话注解**:UI 是仪表盘,UX 是**这趟车能不能把你送到地方** —— 包括找车、上车、途中、下车之后的全部环节。
> 神经学与心理学早就说不清「感知」怎么量化,所以 UX 是主观的;但组成它的那些属性(响应时间、步骤数、对比度)是客观的、可量的。

### 两个词的关系:一句话就能切开

NN/g 的原文把这条线画得很清楚:「必须把**总的用户体验**与**用户界面**区分开,尽管 UI 显然是设计里极重要的一部分」——
举的例子是一个影评网站:**即使找电影的 UI 完美无缺**,只要它的片库只有大厂电影,想看某部独立小片的用户,UX 依然是差的
([NN/g: The Definition of User Experience (UX)](https://www.nngroup.com/articles/definition-user-experience/))。
同一篇文章还补一句:**可用性是 UI 的一项质量属性**,而「总的用户体验」是比它**更宽**的概念
([NN/g: Usability 101](https://www.nngroup.com/articles/usability-101-introduction-to-usability/))。

## 二、对比表

| 名词 | 一句话判定 | 它管什么 | 它保证不了什么 |
| --- | --- | --- | --- |
| UI | 它存在于**屏幕/设备表面**上,看得见摸得着 | 控件、排版、配色、措辞、交互反馈、状态可见 | 用户能不能真把事办成(数据不全、流程太长,它管不着) |
| UX | 它存在于**用户脑子里的整段过程**中 | 从入口到结果的完整路径:找得到、做得完、错了能恢复 | 单个像素的对齐、某个按钮的圆角(那是 UI 的活) |
| 可用性 | 它是**UI 的体检项** | 易学、高效、少出错、用着舒服 | 代表整段体验(影评网站的例子:UI 可用性满分,UX 仍可不及格) |
| 可访问性 | 它问的是**换个人还能不能用** | 键盘可达、对比度足够、色觉障碍也能读出状态 | 一般用户的效率与愉悦(它是下限,不是全部) |

**一句话判定**:问「**它在哪儿**」—— 在屏幕/设备那层就是 UI,在用户经历的整条时间线上就是 UX。
**一句话分工**:UI 决定「这一步好不好操作」,UX 决定「这一趟值不值得」。

## 三、本机实例:把「好看」翻译成可量的数字

主观的感受很难证伪,但 UI 里有一大类东西是**有标准、可计算**的,它们同时决定了 UX:

- **对比度**:WCAG(Web 内容可访问性指南)对 AA 级的硬要求是**正文文字与背景的对比度 ≥ 4.5:1**;
  大号文字(18pt / 24px,或加粗的 14pt)可放宽到 **3:1**
  ([W3C: Understanding SC 1.4.3 Contrast (Minimum)](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html))。
- **行宽**:每行 45~90 个字符(含空格)是最舒服的区间 —— 行太长,眼睛从行尾回到下一行行首的行程变远,容易串行
  ([Butterick's Practical Typography: Line length](https://practicaltypography.com/line-length.html))。

本机这份速览课的样式表 `90-模板/teach-assets/lesson.css` 里,五个正文着色对纸色 `#fdfcf9` 的实测对比度是
**16.96 / 6.40 / 6.23 / 6.02 / 5.19 : 1**,全部过 4.5:1;只有作分隔用的细线 `#d8d4cc` 是 1.44:1 ——
它不是文字,不受 4.5 这条约束。正文宽度设成 `max-width: 46rem`,在 17px 字号下换成汉字约 **43 字/行**。
这是一条两层同时成立的改动:**配色与行宽属于 UI,「读三段不串行、低视力也能读」属于 UX**。

## 四、常见误解

| 说法 | 问题在哪 | 更准的说法 |
| --- | --- | --- |
| 「UX 就是好看」 | 把感受等同于外观 | 好看是 UI;UX 是整段经历,含能不能办成事 |
| 「UI 好看 = UX 好」 | 影评网站的例子直接证伪 | UI 是 UX 的必要条件,不是充分条件 |
| 「UX 只管屏幕里的东西」 | NN/g 的定义里含购买、开箱、售后 | 屏幕之外的环节同样是 UX |
| 「UI/UX 只是设计师的事」 | 后端只返回 200 条中的前 20 条,UX 当场崩 | 数据、超时、错误文案都是体验的一部分 |
| 「可访问性 = 给残疾人做的额外版本」 | 键盘可达、对比度达标对所有人都有效 | 它是下限,不是特殊分支 |

## 五、和相邻术语的关系

| 术语 | 一句话定义 | 与这两个词的关系 |
| --- | --- | --- |
| **人机交互(HCI)** | 研究人与计算机如何相互作用的学科 | UI/UX 都是它的研究对象;HCI 是学科,UI/UX 是对象 |
| **交互设计(interaction design)** | 设计「操作 → 反馈」这一来一回的动作序列 | 落在 UI 与 UX 的接缝上:动作发生在 UI 上,效果体现在体验里 |
| **信息架构(information architecture)** | 内容怎么分类、怎么命名、怎么被找到 | 影评网站那个例子失手的地方,往往是它 |
| **可用性测试(usability testing)** | 找人真用一遍、把卡住的地方记下来 | 量 UX 的主要手段;它测的是过程,不是像素 |
| **设计系统(design system)** | 一套可复用的组件 + 规范 + 令牌 | 把 UI 的重复决策固化,顺带保住可访问性的下限 |

**一句话总结**:UI 是**那一层看得见的表面**,UX 是**用这层表面走完的整段路**;两者既不同层也不对立 ——
UI 做砸了 UX 一定好不了,UI 做满分 UX 仍可能不及格。
