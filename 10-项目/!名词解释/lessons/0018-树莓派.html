树莓派:一块信用卡大小、能跑完整系统的单板计算机

你能做到:拿到一块小板子就说出它属于哪一档 —— 单板计算机 single-board computer(SBC)、单片机 MCU(microcontroller unit,微控制器), 还是一台普通 PC;要给家里添一台常年开着的小机器时,知道该选哪一档。

1 | 定义

树莓派(Raspberry Pi,单板计算机 SBC,single-board computer)是一块信用卡大小、能跑完整操作系统的计算机: 处理器、内存、网络接口和一排可编程针脚,全都焊在一块电路板上。 一张信用卡大小的板子,插上卡、接上电,跑起来就是一个完整的 Linux 小电脑,还能用那排针脚直接接传感器和继电器。

它和「一块芯片」的分界只有一条:树莓派上跑着操作系统,通常是 Raspberry Pi OS(Linux 的一种发行版); 芯片上只有电路,程序得自己把硬件从头管到底。

2 | 它解决什么麻烦

「让一个程序一直开着」和「让程序碰到真实硬件」,原本是两件都不划算的事:

  • ① 常驻服务用主力电脑太贵。普通 PC 常年开着要几十到几百瓦,还有风扇噪音;而一台小服务真正需要的算力很小。
  • ② 想碰硬件,门槛却压在最底层。从零学控制硬件,通常要先画板、焊接、写裸机程序,对只会写软件的人是一道硬墙。
  • ③ 教学和试验要便宜、要统一。一人一块、折腾坏一块也不心疼,才谈得上反复试。
  • ④ 联网与实时控制最好分家。要联网、要存数据的活,和要毫秒级响应的活,塞进同一颗芯片里会互相拖累。

树莓派用「一台便宜、低功耗的完整小电脑」回答了前三条;第四条则是它和单片机搭档的场合 —— 各做各擅长的那一段。

3 | 它怎么解决

它把一台电脑该有的东西缩到一块板上,这正是「单板」两个字的含义:

  • ① SoC(system on a chip,片上系统):CPU 与 GPU 做在同一颗芯片里,是整块板的大脑。
  • ② 内存:直接焊在板上,不能像台式机那样插条升级,容量在买的时候定死。
  • ③ microSD 卡槽:它在树莓派里扮演硬盘的地位 —— 系统、程序、数据默认全住在这张卡上。
  • ④ GPIO(general-purpose input/output,通用输入输出)排针:一排可编程针脚,程序读它就知道按钮按没按,写它就能点亮灯、驱动继电器。
  • ⑤ 接口:USB 与以太网口,较新的型号还带 Wi-Fi 与蓝牙,所以不接屏幕也能进网络。
  • ⑥ 供电:USB-C 或 micro-USB 口,插上 5V 电源就开机,不要机箱、也不要风扇。

从空卡到能登进去,只有三步:把系统镜像 image(整张卡的内容一次写进去的文件)烧到 microSD 卡上 → 插卡通电,它自己启动 → 在配置里打开远程登录,之后从别的电脑用 ssh 进去敲命令。 不接屏幕、只敲命令的用法叫无头运行 headless(也就是命令行 CLI);想当台式机用,接上屏幕和键盘也一样能开机(那是图形界面 GUI)。

针脚怎么碰到硬件:操作系统里跑一个普通程序(比如 Python 脚本)去读写 GPIO 针脚,软件就控制住了硬件。 要毫秒级不抖动的活,就让针脚后面挂一块单片机:树莓派发命令、收数据、存起来、再送到网络上,单片机贴身执行。

4 | 用它的代价

  • ① 存储卡会写坏。microSD 卡的写入次数有上限,长期写日志、跑数据库很快把它耗掉;要把日志和数据写到外置硬盘或通过网络发走,卡上只留系统。
  • ② 对供电敏感。电压不足时,固件 firmware会记下欠压 undervoltage 并自动降频 throttling 保命,严重时随机重启;电源要按型号查官方要求的电流(Pi 4 是 5V/3A、Pi 5 是 5V/5A),线要短要粗,别拿手机充电头凑合。
  • ③ 高负载会降频。持续满载时温度升上来,它自己把频率降下去,速度肉眼可见地掉;要长时间满载就得加散热片或风扇。
  • ④ 算力只够小服务。模型推理、大规模编译、高并发的站点,它扛不动 —— 那本来就该交给 PC、迷你主机或云服务器。在它上面挑做法,先看时间复杂度与空间复杂度:量级选错了,换哪块板子都追不回来。
  • ⑤ 针脚是 3.3V 电平。接 5V 器件要么加电平转换,要么可能烧掉针脚;继电器、电机这类大电流负载中间还得有驱动电路,不能直接从针脚取电。

5 | 真实使用场景

场景一:家里放一台当小型服务。想要一个自己的网页、一个定时备份,或一个 24 小时不停的爬虫,又不想让主力电脑一直开着:

  1. 给 microSD 卡烧上 Raspberry Pi OS,插卡开机,在首次配置里打开远程登录与 Wi-Fi。
  2. 从笔记本用 ssh pi@raspberrypi.local 进去 —— 同一 Wi-Fi 下,系统自带的 mDNS 名字解析会帮你找到它,不必先查 IP。
  3. 要跑的是几小时的编译或同步,先在 tmux 里开一个会话再跑:SSH 断了,它也不会停。
  4. 装上 Docker,用一条命令起一个服务:docker run -d -p 8080:80 nginx。
  5. 手机连同一个 Wi-Fi,浏览器打开 http://raspberrypi.local:8080 就能看到页面;整台机器几瓦功耗,常年开着也不心疼。

场景二:接一个传感器,把读数记下来。想知道家里的温湿度随时间怎么变:

  1. 把 DHT22 温湿度传感器接在 GPIO 针脚上 —— 它是 3.3V 器件,电平正好对得上。
  2. 写一个 Python 脚本,用 adafruit-circuitpython-dht 或 Adafruit_DHT 这类库把读数取出来。
  3. 用 cron 每 5 分钟跑一次脚本,把时间与温湿度追加写进一个 CSV 文件。
  4. 想看曲线,就在这台机器上跑 Grafana,让它的 CSV 数据源插件直接读这个文件画图;懒得起服务时,一条 python -c "import pandas as pd, matplotlib.pyplot as plt; pd.read_csv('dht.csv').plot(); plt.savefig('dht.png')" 也能出图。数据一多一重要,就把文件写到外置盘或推到别处,别留在卡上。

6 | 和相近的东西怎么分

这几样都常被叫作「一块小板子」,分它们的轴只有两根:跑不跑操作系统、功耗在什么量级。逐个说清它们各是什么、和树莓派是什么关系:

名词它是什么和树莓派什么关系什么时候选它
树莓派 Raspberry Pi一块跑完整操作系统的单板计算机本课讲的这一档:软件随便装,针脚直接接硬件常驻小服务、要联网与存储、顺便接几个器件
单片机 MCU(如 STM32)一颗芯片,没有操作系统,上电就跑你写的那一个程序同样从针脚接硬件,但少了操作系统这一层;它就是给树莓派补毫秒级实时的那一块要毫秒级响应、要电池撑很久
Arduino面向电子入门的单片机开发板,底子是 MCU,配一套简单的编程环境与现成模块和单片机同一档,同样没有操作系统;比树莓派更贴电路、更远于系统与网络学电子、做小装置、把身边的东西点起来
普通 PC / 迷你主机完整主机,有风扇有硬盘,功耗几十到几百瓦和树莓派同为跑完整系统的机器,差在功耗量级与那排针脚重计算、编译、跑大服务、当桌面

一条分界:树莓派和 PC 都跑完整系统,差在功耗与那排针脚;树莓派和单片机都接硬件,差在有没有操作系统。

再补一句:树莓派不是唯一的单板计算机,同类产品还有不少 —— 分档的判据一样,品牌不是判据。

7 | 常见误解

  • ① 「树莓派就是 Arduino。」不是。树莓派跑完整操作系统,能联网、能存数据、能同时开好几个程序;Arduino 底子是单片机,上电就跑你那一个程序,胜在毫秒级响应、省电、接线简单。
  • ② 「插上电就是服务器了。」还得烧系统、配网络、防掉电。存储卡和电源是它最常坏的两处,断电后要能自己起来,才谈得上常驻。
  • ③ 「性能这么弱,只能玩。」小流量的网站、爬虫、家庭自动化、内网文件共享都够用;不够的是模型推理、大规模编译和高并发 —— 那是选错了档,不是它的毛病。
  • ④ 「GPIO 针脚什么都能接。」针脚是 3.3V 逻辑电平,直接接 5V 器件有烧掉的风险;电机、继电器这类大电流负载要经过驱动电路,不能直接从针脚取电。
  • ⑤ 「不接显示器就没法用。」无头运行是常规做法:配置里打开远程登录,用 ssh 进去,机器放在角落或机柜里都行。

8 | 练习

三题自测,每题只有一个正确选项;选完立刻看到解释。

1. 树莓派和 Arduino 最根本的区别在哪一面?

对。分档的轴是「跑不跑操作系统」:Arduino 底子是单片机,上电就跑你那一个程序;树莓派上面是一整个 Linux,能装软件、能同时跑好几个服务。贵不贵、能不能联网只是它带来的结果。

2. 要让一台小机器常年跑网站和数据库,选哪一档?

对。要同时有系统、网络、存储和常驻服务,就得是能跑完整操作系统的机器;单片机省电、实时,但没有系统可用;传感器只是采集端。台式机当然也跑得动,但功耗与噪音都不像「一台常年开着的小机器」。

3. 树莓派这一类单板计算机,短板是什么?

对。短板在实时:上面跑着通用操作系统,调度给不出毫秒级的确定时刻,所以那类活要交给贴身的单片机。其余三条与事实相反:它能跑完整系统,自带 Wi-Fi 与以太网口,USB 上也能挂外置硬盘。
