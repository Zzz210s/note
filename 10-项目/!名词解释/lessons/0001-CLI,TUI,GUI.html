CLI、TUI、GUI:你和电脑说话的三条通道

这节课的胜利:看到一个软件,能指出它给你的是哪一条通道(常常不止一条), 并说出这条通道的强项与它的对价。

一句话定位

三种界面说的是同一件事的三种做法:你用什么方式把意图交给电脑、电脑用什么方式把状态回给你。 判据只有两条:屏幕上画的是字符流、字符画出的面板,还是像素; 以及你是敲完整命令、按选项移动,还是用鼠标点。

三种做法:痛点 / 定义 / 大白话

CLI:把操作变成可复现的文字

痛点:每一步操作都绑在一次点击上,就没法批量、没法复现、没法远程,也没法让脚本替你干活。

定义:CLI(Command Line Interface)以文本命令逐条输入,程序以文本回应 (Wikipedia: Command-line interface)。

大白话:你敲一句、它办一件事并回你几行字 —— 而这几行字是纯文本, 所以能原样贴给别人、写进脚本,或直接喂给下一条命令。

TUI:在终端里给出看得见的状态

痛点:纯 CLI 一次只回一段文字,看不到持续变化的状态(进度、列表、当前选中项); GUI 又要求图形环境,在服务器上太重。

定义:TUI(Terminal User Interface)用字符在终端里画出面板、表格、状态, 并接受键盘交互(Wikipedia: Text-based user interface)。

大白话:看着像图形界面,底层还是文字 —— 所以它也能在 SSH 里跑。

GUI:把门槛砍掉

痛点:早期只能用命令行,普通人要背几十条命令才能干活,这是电脑普及路上最大的障碍。

定义:GUI(Graphical User Interface)用窗口、图标、菜单、按钮表达功能, 由指针设备直接点选(Wikipedia: Graphical user interface)。

大白话:功能摆在菜单里,看得见就能点 —— 不用先知道那条命令叫什么。

对比表

名字一句话判定什么时候它不适用
CLI只有文本流,一次一条命令要「发现功能」时门槛高:不先知道命令名就无从下手
TUI用字符画出面板,键盘推进画图、多窗口并排、精细排版做不到
GUI用像素画出窗口,指针点选远程带宽吃紧、要批量复现时,它反而是阻力

它们不是替代关系,而是同一款软件可以同时给出的通道:VS Code 是图形界面, 但自带终端(CLI 通道)、有命令面板,也能用 code . 从命令行启动。每个通道的取用代价不同: CLI 要你先知道名字,换来可复现;GUI 要你伸手去点,换来可见性。

判据要落在界面怎么画出来的,不是配色。终端窗口里敲 code .,打开的仍是 GUI 程序; vim 支持鼠标点光标,它仍是 TUI。管子也一样: Wikipedia: Pipeline (Unix) 让一条命令的输出直接成为下一条的输入,这件事只有在文本通道里才成立。

常见误解

  • 「黑框就是 CLI」不成立:黑色只是配色,终端窗口里能启动图形程序。
  • 「能用鼠标就是 GUI」不成立:判据是界面怎么画,鼠标只是一种输入设备。
  • 「终端 = Shell = 命令行」不成立: 终端模拟器是那个窗口, Shell是窗口里跑着、听懂命令并启动别的程序的解释器, 「命令行」则是你敲字的那一行位置 —— 三个词不在同一层。

辨析练习:这属于哪种形态?

共 4 例。选中后立刻给反馈,答错可以再试 —— 判据在上一节的对比表里。

1. 你 SSH 连上一台服务器,敲一行命令回车,屏幕回你 6 行文件名,没有任何全屏面板。

是 CLI:没有全屏面板,一次只回一段文本。SSH 里它最好用,因为只传字符、不传画面。

2. 你打开 vim 写代码:屏幕上是带边框的面板与快捷键提示,用方向键移动选中项。

是 TUI:用字符画出了「面板」,通道仍然是文本 —— 所以它同样能在 SSH 里跑,这是它比 GUI 强的地方。

3. 你双击桌面上的图标,窗口弹出来,里面有菜单、按钮和滚动条。

是 GUI:界面由像素画成,功能摆在菜单里点一下就出来。代价是远程使用要一帧帧传画面,网络一差就卡。

4. 你在 vim 里能用鼠标拖动滚动条、点一下把光标放过去。

是 TUI:「能用鼠标」不等于 GUI。判据看的是界面怎么画出来的 —— vim 画的仍然是字符,鼠标只是它额外支持的一种输入。

自测(选项一样长,别从长度上猜)

1. 同一件事要在图形界面里重复做 20 遍,最该换哪种?

对。CLI 的长处就是「一条命令可复制、可重复、可写进脚本」;GUI 里这件事要点 20 遍,而且很难描述给别人听。 经验法则:一件事在图形界面里重复点超过 3 遍,就该去找它的命令写法。

2. 远程连接里 TUI 与 CLI 比 GUI 顺,原因是什么?

对。远程桌面本质是把画面一帧帧传过去,网络一差就卡;TUI 与 CLI 在终端里跑,SSH 只传文字,几百 KB 的网速就够用。 这也是服务器上几乎见不到图形界面的原因。

3. 「VS Code 有图形界面,又能用 code . 启动」说明什么?

对。界面形态是一个软件可以同时提供的通道,不是软件的分类标签。 Git 也是这样:有 git(CLI)、lazygit(TUI)、GitHub Desktop(GUI)三种外壳。
