## 任务清单(参考:Xray Project X 官方文档、VPS 搭建代理完整教程)

- [ ] 原理:V2Ray / Xray / Shadowsocks / Trojan 区别;VLESS+Reality 优势
- [ ] VPS 选购:最低 1核/512MB/10GB;装 Debian 12 或 Ubuntu 22.04
- [ ] 安全基线:SSH 密钥登录、关闭密码、UFW 防火墙、Fail2Ban
- [ ] 安装配置 Xray(xray-core):开启 VLESS + Reality
- [ ] TLS 证书配置(或借助 Reality 免除再用证书)
- [ ] 启用 BBR 加速(内核已内置,开启即可)
- [ ] 客户端连接并验收(延迟/速度/稳定性)
- [ ] 记录:把部署命令与踩坑写成本仓库成品笔记
