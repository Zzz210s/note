# 免费服务器资源全景(2026-10 核实)

**口径:** 数字均为 2026-10-02 逐个抓取官方页面所得;二手来源(博客/CSDN/掘金)会明确标注。写「未核实」的条目没有回到一手来源确认。

---

## 一句话结论

「免费 + 长期 + 稳定」三者同时成立只有两类:**不给你整机、但额度稳定**的边缘/托管平台(Cloudflare 为首),以及**大厂永久免费层里最小的那几档**(Oracle 2 核 12G、GCP e2-micro、AWS 部分 always-free)。

凡是自称「永久免费 VPS」的,要么靠签到/保活续命(公益云,随时停服),要么要绑卡并接受封号风险(甲骨文)。免费层当**验证层 + 备用节点**,主力交付仍然要付费。

判断顺序:能不能长期挂着 → 要不要绑卡 → 有没有休眠/回收规则 → 出事时数据能不能带走。

| AMD Micro | 2 台 VM.Standard.E2.1.Micro(1/8 OCPU、1 GB 内存) |

| 块存储 | 200 GB 总量 |
| 出站流量 | 10 TB/月 |

| 对象存储 | 10 GB |

三条必须知道的规则:

1. **2026-06-15 起 ARM 免费额度砍半**:非 PAYG 账户只能 2 OCPU / 12 GB([Oracle 社区公告](https://community.oracle.com/customerconnect/discussion/970310/oci-always-free-updated-ampere-a1-compute-allocation)、[InfoQ 报道](https://www.infoq.com/news/2026/07/oracle-cloud-free-tier-limits/))。**升级为 Pay As You Go 后 A1 仍保留 3,000 OCPU 小时 / 18,000 GB 小时/月(≈4 核 24 G)**([官方文档](https://docs.oracle.com/en-us/iaas/Content/Compute/References/arm.htm))。
2. **空闲回收**:7 天内 95 分位 CPU < 20%、网络 < 20%、内存 < 20%(A1)—— 可能被判定为空闲并回收([Always Free 资源文档](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm))。
3. **注册玄学 + 容量不足**:主区域注册后不可改;东京/首尔/新加坡的 ARM 常报 `Out of host capacity`,抢实例靠 API 脚本反复重试。

## 四、免费主机(能 SSH,接近小 VPS)

### Serv00(目前口碑最好的一档)

波兰非营利项目,FreeBSD,官网 [serv00.com](https://www.serv00.com/):

| 项 | 额度 |
| --- | --- |
| 存储 | 3 GB SSD |
| 内存 | 512 MB |
| 流量 | 不限 |
| 站点 | 100 个,免费二级域 `你的名字.serv00.net` |
| 数据库 | 10 MySQL + 3 PostgreSQL + 3 MongoDB |
| 端口 | 3 个 TCP/UDP(可跑自定义进程) |
| 进程 | 15 个常驻 |
| 其他 | SSH、Let's Encrypt 自动证书、7 天备份、机房在欧盟 |

要求:每 3 个月至少登录一次面板或 SSH,否则可能回收账号;注册名额分批开放,且对注册 IP 干净度敏感(社区经验:挂干净节点注册成功率更高)。

### 签到/保活型公益云

- **FreeCloud**([freecloud.ltd](https://www.freecloud.ltd/))——LXC 轻量容器,独立 IPv6 + 共享 IPv4,每人限 1 台,每 10 天免费续期一次;旗下另有 NAT / 面板 / Web 等多个子站,靠每日签到积分续期(例如 0.01 积分续 3 天、1 积分续 30 天等,各站规则不同)
- **雨云** —— 积分制,签到与任务攒积分兑换或续期云服务器/游戏云,1 元 ≈ 2000 积分

> 这类平台的共性:**寿命取决于运营方心情**。2026-05 ClawCloud Run 停服就是最新案例。放玩具可以,放数据不行。另外它们多数在条款里禁止代理/商业用途,滥用会被清号。

## 十、白嫖纪律(踩坑总结)

1. **绑卡就是风险开关**。试用到期自动转按量计费;AWS Free plan 6 个月后自动关账户;Oracle 有封号与空闲回收;Zeabur 试用结束不取消直接扣费。
2. **免费层只当验证层**。唯一数据、主库、生产流量都不放;能带走的东西(容器定义、配置、备份)留在自己手里。
3. **休眠与冷启动是常态**。Render 15 分钟、Neon 5 分钟、Supabase 1 周 —— 需要常驻就用 cron 保温(GitHub Actions / Workers cron)。
4. **保活规则要写进脚本**。Oracle 7 天 20% 阈值、Serv00 每 3 个月登录、公益云签到 —— 靠记性一定忘。
5. **免费节点/机场聚合仓库**(如 GitHub 上 `Pawdroid/Free-servers`、`ermaozi/get_subscribe` 这类订阅聚合)只适合临时救急:共享节点的隐私与可用性都不可控,不要在其上登录重要账号。
6. **每季度做一次迁移演练**。历史上的死法都是「突然公告 + 两周内备份」。

## 十一、落到本项目(搭建代理服务器)

- **练手 / 面板调试**:Cloudflare 免费栈 + Serv00(3 个 TCP/UDP 端口、能跑自定义进程、免绑卡),够把 3x-ui 流程走通;注意平台条款通常禁止代理用途,只作学习环境。
- **长期节点**:Oracle 免费 ARM(风控 + 容量 + 缩水三件事都要接受),或直接上年付低价 VPS(见 [[VPS商]])。
- **结论**:免费层适合做**备用节点与压测环境**;对外可用的主力节点仍建议付费,理由是免费层的回收、封号、限速都发生在最不方便的时候。
