先学会"找得到":命令面板与快速打开

这节课的胜利:用键盘完成 5 个动作 —— 打开设置(JSON)、按文件名跳转、跳到指定行、切换终端、执行任意命令 —— 全程不碰鼠标菜单。这 5 个动作覆盖你日常 80% 的"翻菜单"时间。

为什么是这一步

使命里写着:这是每天用最久的工具,每一点效率改进都会复利到所有其他项目。 而复利的起点不是装插件,是知道所有功能都从同一个入口进。 你本机装的是 VS Code 1.138.0,下面的按键与官方文档完全一致。

最小知识:三条

  1. 命令面板是万能兜底。任何功能(哪怕你不知道它叫什么)都能在面板里按关键词搜到 —— 记不住快捷键时,它救场;用多了,你自然会记住那几个高频的。
  2. 同一个输入框,两种模式。Ctrl+P 打开时是"跳文件";在框里先敲一个 > 就切成"执行命令"; 先敲 # 是搜符号,: 是跳行号。不必记四个快捷键,记一个 + 四个前缀。
  3. "按文件名跳"与"按内容搜"是两件事。前者快(Ctrl+P),后者用全局搜索(Ctrl+Shift+F)—— 找文件别用搜内容,那是本库 141 篇笔记都能搜出来时的自找麻烦。

动手:五个动作,一次做完

先在本库根目录用命令行打开编辑器(这一步本身也是技能):

cd /f/0-Note
code .

然后依次做这五件事(建议把每个动作重复三遍,肌肉记忆靠重复不靠理解):

#动作按键你会看到
1打开命令面板,搜 "settings json"Ctrl+Shift+P → 输入 settings json能选到"打开用户设置(JSON)"
2按文件名跳到一篇笔记Ctrl+P → 输入 课程地图列出所有课程地图,回车打开
3跳到第 42 行Ctrl+P → 输入 :42光标落到当前文件第 42 行
4切换集成终端Ctrl+`(反引号)下方终端开/关
5执行"格式化文档"Ctrl+Shift+P → 输入 format看到格式化相关命令(先别执行,markdown 不一定配了格式化器)

自测(选项一样长,别从长度上猜)

1. 命令面板最核心的用途是?

对。它的价值在于"你不必记住功能在哪个菜单、叫什么名字" —— 输入关键词就能搜到。这是所有快捷键的兜底。

2. 「快速打开」与「全局搜索」的区别?

对。Ctrl+P 按文件名跳(快);Ctrl+Shift+F 按内容搜(慢但全面)。在本库这种上百篇笔记的仓库里,混用会浪费大量时间。

3. 多光标最实用的两种生成方式?

对。两种最实用的方式:① 按住 Alt(换档)用鼠标点选多处;② 用快捷键 —— Ctrl+Alt+↓ 向下加光标、Ctrl+D 选中下一个相同词。多光标是原生功能,不需要装任何插件。
