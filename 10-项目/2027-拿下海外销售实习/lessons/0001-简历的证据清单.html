简历的证据清单:先把"能证明什么"写出来

这节课的胜利:产出 5 张证据卡 —— 每张写清「场景 / 你的动作 / 可验证的结果 / 它证明什么能力」, 再把这 5 张按你目标岗位的优先级排序。这一步做完,简历只是"把证据卡翻译成排版"。

为什么是这一步

使命说得很直接:你的组合(软件能力 + 硬件与物联网课程 + 梅西大学海外经历 + 西班牙语) 正好命中技术型海外销售的 JD,但缺两样:一段真实的销售实践、拿得出手的技术作品。 而简历的问题从来不是排版 —— 是没有证据可写。所以第一节课不写简历,先盘点证据。

最小知识:三条

  1. 技术型销售简历的读者只关心两件事:你懂不懂技术(能不能听懂客户的问题), 以及你能不能对客户讲清(有没有对外表达的证据)。纯技术简历按这个标准看,一半内容是不相关的。
  2. 一条合格的证据 = 场景 + 动作 + 可验证的结果。 "熟悉嵌入式"不是证据;"在树莓派上部署 RFID 点唱机,跑通刷卡播放并录了演示视频"才是。 有数字更好:耗时、规模、金额、覆盖率。
  3. 排序按岗位优先级,不按时间。你要投 IoT 模组 / AI 硬件 / 通信设备 / 储能出海 / 工业自动化五类, 每类关心的证据不同 —— 同一批证据,对不同公司要换顺序(甚至换措辞)。

动手:从你的真实项目里抽 5 张证据卡

打开 岗位池.md 与 项目说明,照下面格式填 5 张 (素材都在你自己的项目里,不用编):

证据卡 #1
- 场景:____(什么项目 / 什么约束)
- 动作:____(你具体做了什么,动词开头)
- 结果:____(可验证:链接 / 数据 / 可复现步骤 / 别人能用)
- 证明:____(技术深度 / 对外表达 / 跨文化沟通 / 交付能力)
- 最适用:____(IoT 模组 / AI 硬件 / 通信设备 / 储能出海 / 工业自动化)

可用的素材(本库里已有的事实,挑你最有话说的 5 个):

素材它天然证明了什么
RFID 点唱机:从采购到刷卡通播完整交付链路(读文档 → 采购 → 最小系统 → 跑通),产出实物
Zephyr 上游贡献:PR 被合并(如 #119887)能按工业级项目的规矩协作(DCO / review / CI),英文书面沟通
L-ink 名片复刻(进行中)硬件链路理解(NFC 取电 / 低功耗 / 墨水屏),有实测数据
西班牙语 A1 → B2(一年计划,进行中)面向拉美/西班牙市场的沟通能力,且是"长期自我管理"的证据
六级每日四件套(进行中)英语硬指标 + 可展示的坚持记录(每天一条 commit)

写完做两件事:

  1. 把 5 张卡按"我最想投的那一类企业"重新排序,并写下一句排序理由。
  2. 挑出其中最弱的一张,写下"要补什么才算强"—— 那就是后面几节课的重点。

自测(选项一样长,别从长度上猜)

1. 下面哪一条算合格的证据?

对。它含场景(点唱机)、动作(部署)、可验证结果(演示视频)。其余三条是"形容词",面试官无法验证 —— 技术型销售的简历最忌讳这个。

2. 技术型销售的简历,读者最先看什么?

对。技术型销售的核心能力是"把技术讲成客户能懂的价值" —— 所以简历要同时体现技术深度与对外表达(文章、演示、社区投放都算)。

3. 为什么同一批证据要对不同公司换顺序?

对。IoT 模组岗最关心硬件与模组理解,储能出海更关心行业与海外市场认知 —— 同一批证据,把最相关的那张放到最前面,命中率完全不同。
