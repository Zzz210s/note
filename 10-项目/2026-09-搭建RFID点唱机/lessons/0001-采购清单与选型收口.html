采购清单与选型收口

这节课的胜利:把三件事一次定死 —— 树莓派型号、读卡器路线(USB 直插 vs GPIO 模块)、装 v2 还是 v3 —— 并给出下单清单。定完这一节,你就能真的下单,而不是继续"再看看"。

为什么是这一步

使命写的是"读文档 → 采购 → 最小系统 → 跑通 → 定制"这条完整链路。 你现在卡在第一步的尾巴:清单已列、还没下单。而采购一旦错了,后面每一步都在还债 —— 所以这一节不学新知识,只做一件事:拿官方文档校对自己的决定。

最小知识:三条会影响你花钱的事实

  1. 官方明确说"免焊接"。README 第一段写着:all plug and play via USB, no soldering iron needed —— USB 即插即用,不需要烙铁。也就是说:USB 读卡器是官方主推路线;GPIO 模块(RC522)是"更练手"的自选路线,不是必需品。
  2. 项目有两个版本,而且正在换代。v2 已进入维护模式(不再加新功能);v3(future3)即将成为默认版本, 用 Python 重写核心、带插件系统与响应式 Web 界面。你装哪个,决定了后面所有教程、命令与界面长什么样。
  3. 读卡器决定后面能玩什么。USB 读卡器只能读卡号(刷卡即播够用);MFRC522 走 SPI,除了读卡号还能读写卡上的数据块 —— 这也是你下一个项目(2026Q4-复刻L-ink智能名片)会用到的能力。

动手:一次核对,三个决定

打开官方 README(不用 clone,浏览器即可),边看边填这三行:

https://github.com/MiczFlor/RPi-Jukebox-RFID
决定选项判据(用官方原文回答)
① 树莓派型号 3B+ / 4 / 5 / Zero 2 W 官方支持的型号列表里有没有它?音频输出(3.5mm/USB/HDMI)你要用哪个?
② 读卡器路线 USB 读卡器 / MFRC522 模块 你要的是"最快跑通"(USB)还是"练 GPIO + 为下个项目铺路"(模块)?
③ 版本 v2 / v3(future3) 你要跟哪一份安装文档?v3 的安装页在 documentation/builders/installation.md(分支 future3/main)

然后写下你的下单清单(示例骨架,按你的决定填):

- 树莓派:____(型号)            ￥____
- microSD:16G+ 卡 + 读卡器        ￥____
- 读卡器方案:USB / MFRC522(含排线) ￥____
- 电源:5V/3A(官方推荐规格)        ￥____
- 音频:3.5mm 音箱或 USB 声卡       ￥____
- RFID 卡:NTAG213 白卡 ×5         ￥____
合计:￥____(项目说明给的预算是 300~600 元)

把这三行决定写进 项目说明的「踩坑记录」上方(或直接更新那条"清单已列,定 RC522,待下单"的待办)—— 写下来才算决定。

自测(选项一样长,别从长度上猜)

1. 官方 README 对硬件门槛的说法是?

对。官方主推 USB 路线:all plug and play via USB, no soldering iron needed。选 GPIO 模块是你的自由(为练手),但它不是"必须"。

2. v2 与 v3 的现状,哪种说法对?

对。v2 进入维护模式(不再加新功能),v3(future3)"becoming mature and will soon be the new default"。装哪个版本,决定你跟哪一份文档。

3. 读卡器路线(USB 直插 vs GPIO 模块)的取舍?

对。USB 路线最快跑通(官方主推);MFRC522 走 SPI、要接线,但能读写卡上数据块 —— 正是下个项目(L-ink 名片)要用的能力。
