Kubernetes(容器编排):课程地图

这是全局路线,不是课本身。每节课的实际难度、例子与测验,会按你上一节的真实表现校准(最近发展区原则)—— 所以顺序可能微调,但"下一步学什么"永远有答案。想跳课、换顺序、加课,直接说。

为什么这么排

先在单机上把集群跑起来(有反馈才有动力),再逐个认识核心对象,然后才是声明式 YAML 与网络;最后才看边缘联动。

课程序列

课号标题这节的胜利(可验证)前置状态
0001核心对象:Pod / Deployment / Service说清三者各自的职责与协作关系(不用背 YAML)无已出课
0002minikube 起集群与 kubectl 速查本地集群跑起来,能用 kubectl 看节点、Pod 与日志0001待开
0003声明式 YAML:写一个 Deployment手写 Deployment + Service 清单并 apply,说清声明式与命令式的差别0002待开
0004网络与服务发现说清 ClusterIP / NodePort / Ingress 的差别,并让 Pod 之间能互通0003待开
0005控制器与滚动更新观察 Deployment → ReplicaSet → Pod 的关系,并做一次滚动更新与回滚0004待开
0006边缘联动:KubeEdge 与边缘函数说清 KubeEdge 的 CloudCore/EdgeCore 架构,并与边缘函数对比定位0005待开
0007实战:在 minikube 上部署一个小服务把一个小服务(与 Docker 项目联动)完整部署并访问到0004待开
