# Mission: Markdown(语法与结构化文档)

> `teach` 教学工作区协议文件,与 [项目说明](<./!项目说明.md>) 配套(项目说明管任务与进度,本文件管「为什么学」)。
> 教学决策(下节教什么、给哪些资源、设计什么练习)都回到这份文件上。

## Why

这个库的每一篇笔记、每个项目的 README、以及将来给 Zephyr 提的文档 PR,都靠 Markdown 写出来。它是最低成本的表达杠杆:语法越小,写错越亏。

## Success looks like

- 能写出含标题/列表/表格/代码块/图片/链接/任务列表的完整文档
- 能写出符合 Standard Readme 规范的仓库 README(结构、徽章、许可证段)
- 能讲清 Markdown 方言差异(CommonMark vs GitHub Flavored)与锚点/slug 规则
- 在本库里实际用对:锚点跳转、双轨链接(`[[双链]]` vs 相对路径)不再写错

## Constraints

- 窗口 2026-08-26 → 2026-12-31;当前状态:进行中
- 主教材是菜鸟教程(runoob.com)的 Markdown 章节,按章节推进
- 以本库为练习场:学到的语法立刻用在正在写的笔记里

## Out of scope

- 不学静态站点生成器(Hexo/Hugo/Astro 等) —— 那是「搭建网站」的范畴
- 不学 HTML/CSS 细节,只到「知道 Markdown 渲染成什么」
