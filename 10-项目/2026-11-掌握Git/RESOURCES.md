## Knowledge

- [Pro Git(官方书,中文版)](https://git-scm.com/book/zh/v2)
  Git 的权威教材,免费在线。用在:原理性问题(对象模型、rebase 与 merge 的差别)
- [Git 官方参考手册](https://git-scm.com/docs)
  每个命令的完整参数与行为定义。用在:命令参数拿不准时(比博客可靠)
- [learnGitBranching(中文)](https://learngitbranching.js.org/?locale=zh_CN)
  把分支操作可视化的闯关练习,是本项目「技能训练」的主场。用在:每次学新命令后立刻练
- [jlord/git-it-electron](https://github.com/jlord/git-it-electron)
  命令行 Git 的交互式教程。用在:想用另一种方式巩固基础操作
