Git(版本控制与协作工作流):课程地图

这是全局路线,不是课本身。每节课的实际难度、例子与测验,会按你上一节的真实表现校准(最近发展区原则)—— 所以顺序可能微调,但"下一步学什么"永远有答案。想跳课、换顺序、加课,直接说。

为什么这么排

先看 Git 到底存了什么(对象模型),再看三个区怎么流动,然后才是分支/合并/回滚 —— 不懂对象模型,回滚永远靠背命令。

课程序列

课号标题这节的胜利(可验证)前置状态
0001对象模型:blob / tree / commit / HEAD用 git cat-file 把一个 commit 拆到 blob,说清四者的关系无已出课
0002暂存区:add 与 commit 之间发生了什么讲清工作区/暂存区/仓库三区流动,并用 status/diff/log 定位自己改了什么0001待开
0003分支的本质是指针说清分支就是指向 commit 的指针,并用 switch/checkout 在两条分支间切换0002待开
0004合并与冲突:merge vs rebase手工制造并解决一次冲突,并说清两种合并方式对历史的影响0003待开
0005回滚三件套:reset / revert / checkout在真实仓库里分别用三者撤销一次改动,并说出各自适用场景0004待开
0006远程协作与 PR 流程完成 fetch/pull/push 与一次 PR 往返,并把 .gitignore 写对0005待开
0007实战:learnGitBranching 通关连续通关分支与回滚关卡,并在本库完成一次 feature 分支演练0006待开
