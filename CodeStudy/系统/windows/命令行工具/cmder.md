# Cmder · Claude

Cmder 快捷键（切换不同 Shell / 任务）：

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Shift+1 | Windows PowerShell |
| Ctrl+Shift+2 | 命令提示符 |
| Ctrl+Shift+3 | Azure Cloud Shell |
| Ctrl+Shift+4 | Developer Command Prompt for VS 18 |
| Ctrl+Shift+5 | Developer PowerShell for VS 18 |
| Ctrl+Shift+6 | 设置 |
| Ctrl+, | 命令面板 |
| Ctrl+Shift+P | 关于 |
