# note

个人 markdown 学习笔记仓库,记录编程学习、英语与西班牙语学习内容。

## 目录

- [内容](#内容)
- [结构](#结构)
- [使用](#使用)
- [License](#license)

## 内容

- **CodeStudy**:编程学习笔记,按主题分类(教程 / 服务 / 算法 / 系统 / 通识)。
- **English**:英语学习材料。
- **Español**:西班牙语学习材料,含发音、词汇、语法、外语课程等子目录与素材资源。

## 结构

```
note/
├─ CodeStudy/
│  ├─ 教程/
│  ├─ 服务/
│  ├─ 算法/
│  ├─ 系统/
│  └─ 通识/
├─ English/
└─ Español/
   ├─ 0-发音Pronunciación/
   ├─ 0-词汇Vocabulary/
   ├─ 0-语法Gramática/
   ├─ 1-水木外语-西班牙语/
   ├─ 1-西班牙语语法和词汇/
   └─ assets/
```

## 使用

```bash
git clone https://github.com/eleven237038/note.git
```

用任意 Markdown 编辑器(如 VS Code / Obsidian / Typora)打开阅读,或直接在 GitHub 上浏览。
