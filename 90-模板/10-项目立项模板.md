# 10-项目 项目立项模板

> **属于哪层:** `10-项目\` 项目层。使用时存为 `10-项目\{目标}-{截止日期}\`,如 `10-项目\掌握Markdown-2026Q4\`。
> **作用:** 有**明确目标 + 截止日期**的学习/做项目。一个文件夹承载整个项目,完成后整个移入 `40-归档`。
> **要点:** 项目要有"做完"的概念(有截止),这是它和"常驻通用知识"(两个 `!` 容器)的根本区别。任务清单用 `- [ ]` 可勾选。
> **配套件(建项目时一次生成):** `10-项目/<项目名>/00-索引.md`(索引登记)、`20-知识/.gitkeep`、
> `50-资源/<项目名>/`(仅本机原料,不进版本控制 —— `50-资源/*` 已在 `.gitignore` 里忽略);
> 学习型另出 `MISSION.md` / `RESOURCES.md` / `NOTES.md` 教学协议(A11 守)。
> 命令:`PYTHONIOENCODING=utf-8 python -B 50-资源/工具/vault-check/new_project.py "<项目名>" --type 学习|常驻|通用`
> (`--goal "一句话目标"` 会写进「目标」并带进根索引路线行;`--dry-run` 只打印不落盘;`--backfill` 补齐既有项目)。
> **索引登记不能漏:** 根 `00-索引/00-索引.md` 会同步追加「计划与进度」路线行与「项目清单」表格行、并刷新汇总行 N / M;
> 漏登记会报巡检 A7 / A14。成品知识一律进本项目 `20-知识/`(A10 判路径归属),计划与进度留在项目根。

## 项目封面

- **目标:** 一句话说清要做出什么(可验收)
- **状态:** frontmatter 的 `status`(`todo` / `learning` / `done` / `review`);`done` 是归档判据的第一条
- **起止:** 开始日期 → 截止日期
- **为什么做 / 验收标准:** 做完怎么算"成了"
