# 00-索引 模板(项目索引页)

> **属于哪层:** `10-项目/<项目>/00-索引.md` —— 项目地图,一个项目一页。
> **作用:** 五块固定:`计划与进度` / `原料` / `知识产出` / `模板` / `出口`;`20-知识/` 每篇成品在此**恰好登记一次**(巡检 A4 / A14 守)。
> **要点:** 顶部统计行 `> 本项目知识 N 篇 · 状态 <status> · 覆盖 N/N(100%)` 必须落在前 8 行,故 frontmatter 只留 `type` / `status` 两个字段(A9 读这一行;状态须与 `!项目说明.md` 的 `status` 一致)。
> **何时新建:** 立项目时一并建(或用 `new_project.py`)。

## 空骨架

```markdown
---
type: note
status: learning
---

# 项目名

> 本项目知识 0 篇 · 状态 learning · 覆盖 0/0(100%)

**入口:** [!项目说明.md](<!项目说明.md>)(目标 / 验收 / 任务清单)。

## 计划与进度

- [ ] 第一步

## 原料

- 仅本机原料放 `50-资源/项目名/`(不进版本控制);有值得入库的长文再在此登记一行。

## 知识产出

- [笔记名](<20-知识/笔记名.md>) — 一句话说明 | 类型 | 状态

## 模板

- 暂无专属模板;需要时放项目内 `90-模板/` 或全局 `90-模板/`。

## 出口

- 完成后(四条归档判据全满足,见 `90-模板/40-归档封存模板.md`)整包移入 `40-归档/项目名/`,并在根 [`00-索引.md`](../../00-索引.md) 保留登记行(进度勾掉、清单状态改 `归档`)。
```
