# 00-索引 模板(项目索引页)

> **属于哪层:** `10-项目/<项目>/00-索引.md` —— 项目地图,一个项目一页。
> **作用:** 六块固定:`计划与进度` / `原料` / `知识产出` / `课程` / `模板` / `出口`;`20-知识/` 每篇成品在此**恰好登记一次**(巡检 A4 / A14 守),`课程` 块登记 `lessons/` 与 `reference/`(巡检 A11 守 —— 课只躺在文件夹里、目录页看不出来就叫没适配)。
> **要点:** 顶部统计行 `> 本项目知识 N 篇 · 状态 <status> · 覆盖 N/N(100%)` 必须落在前 8 行,故 frontmatter 只留 `type` / `status` 两个字段(A9 读这一行;状态须与 `!项目说明.md` 的 `status` 一致)。
> **何时新建:** 一条命令生成:`PYTHONIOENCODING=utf-8 python -B 50-资源/工具/vault-check/new_project.py "<项目名>" --type 学习|常驻|通用`(幂等:已存在的件只跳过;`--backfill` 补齐既有项目缺失件)。
> **口径来源:** 本模板的「空骨架」与脚本输出**逐字一致**(统计行与五块由 `50-资源/工具/gen_indexes_render.py` 渲染),一致性由 `50-资源/工具/vault-check/selftest_new_project.py` 锁住 —— 改格式请改渲染器,别只手改这一页。
