# 2026Q4-六级英语每日一练

> 属于 `10-Projects\` 项目层(自然语言英语方向)。目标 + 截止 + 任务清单;完成后整体移入 40-Archive。

- **目标:** 每天四件套——**阅读精读 1 段 + 听力精听 1 段 + 背诵 1 段作文(约80~120词) + 仿写 1 段**,覆盖六级阅读/听力/写作三大模块
- **状态:** 未开始(框架已定)
- **起止:** 起始日 → 考试前(暂定 2026-12 六级)
- **验收:**
  - 阅读:累计**精读 30 段**真题阅读,建「同义替换/长难句」清单
  - 听力:累计**精听 30 段**、跟进「模糊词清单」
  - 作文:每天只背 **1 段**(约 80~120 词),不求当天背完整篇;4~5 天背熟一篇(每篇约 4~5 段),累计背熟 5~8 篇
  - 仿写:累计 30 段,用上今日提取的高分句式
  - 每天一条 commit 推 GitHub 分享

## 一、方法依据(联网调研:新东方 / 沪江 六级备考方法)

- **阅读**:精读真题段落——逐句拆**长难句**、标**生词与同义替换**、理清段落逻辑;比泛读更有效。
- **听力**:精听 + 泛听结合。精听约 30 分钟/天:完整听抓主旨 → 逐句暂停听写 → 对照原文标**连读/弱读** → 跟读模仿 → 裸听;建「模糊词清单」(看着认识、听时不反应的词)。
- **背诵/写作**:不要一次硬背整篇——**每天背 1 段**,理解→标段落主旨→大声朗读→按提纲复述→默写检验(视听口多重记忆);提取高分**句式**下来**仿写**才是得分关键。

## 二、每日流程(四件套)

> **每日模板**(可直接跳转)→ [`90-Templates/六级-每日笔记模板.md`](<../../90-Templates/六级-每日笔记模板.md>)

### ① 阅读精读(≈15min)
1. 精读 1 段真题阅读 / 短文
2. 逐句拆**长难句**(划主干+从句)
3. 标**生词 / 同义替换**(阅读常考"同义改写")
4. 总结段落**逻辑结构**(观点→论据/转折)

### ② 听力精听(≈30min)
1. 预读选项 → 完整听抓主旨
2. 逐句**暂停听写**
3. 对照原文标**连读 / 弱读**
4. 逐句**跟读模仿** → 裸听
5. 记「模糊词清单」
- 碎片时间**泛听**当背景音

### ③ 背诵(≈15min)— 只背 1 段,不背整篇
1. 先**通读**全文 1 遍(熟悉语感,不要求背)
2. 挑**今天这 1 段**(约 80~120 词):理解 → 标主旨/关键词
3. 大声**朗读** 2~3 遍 → 按提纲**复述**
4. 睡前**默写**这 1 段关键句
- 滚动:今天第 2 段 + 复习昨天第 1 段;4~5 天背完一篇

### ④ 作文仿写(≈15min)
1. 从今日阅读 / 范文 / 听力里**提取 1~2 个高分句式**
2. 按今日话题**仿写 1 段**(≥50 词)
3. 标出用到的**模板 / 逻辑连接词**

### ⑤ 复盘与提交
- 记录今日收获 / 卡点 → `git commit`(标题含日期)推 GitHub
