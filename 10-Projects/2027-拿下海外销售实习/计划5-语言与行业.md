# 计划 5:轨 D · 语言与行业

> **给执行者:** 本文件只定义"做什么、做到什么算成、产物放哪"。
> **上级文档:** [项目说明](<!项目说明.md>) / [实施计划总览](<!实施计划.md>)

**目标:** 拿到英语六级与西班牙语 B2 两张证书,并把语言变成"能直接用于客户沟通与面试"的资产 —— 配套一套西语技术销售术语库与一个出海行业情报库。

**为什么:** 语言是本方向唯一的硬门槛,也是本人区别于普通求职者的地方。证书负责过筛,术语库与情报库负责在面试里把语言变成"能用",而不只是"考过"。

**约束:**

- 语言目标**以证书为准**,不因为准备技术线而顺延
- 术语必须经西语一手材料(官方数据手册、厂商西语页面、母语者语料)核对,禁止中译西直译
- 情报库每条都要能追溯来源(公司官网 / 财报 / 官方招聘页)
- 每日投入固定,不与其他轨道抢时间

## 产出物

```
语言与行业/
  01-六级.md            报名、目标分、每周记录、真题成绩
  02-西语B2.md          考试选择、报名、模考记录、口语自检录音
  03-西语术语库.md      中英西三语术语 + 例句(按场景分类)
  行业情报/             每家目标公司一页(20 家)
```

### Task 5.1:英语六级(以证书为准)

**Files:**
- Create: `语言与行业/01-六级.md`
- 复用: `10-Projects/!六级英语每日一练`(已存在的每日一练项目)

**Interfaces:**
- Produces: 六级成绩(简历"证书"栏 + 目标公司 JD 的硬性要求)

- [ ] **Step 1:确认并写死三个时间点**

```markdown
## 时间点
| 项 | 时间 | 状态 |
|----|------|------|
| 报名截止 | | |
| 考试日期 | | |
| 出分日期 | | |
```

判据:三个日期都填了实测值,不留空。

- [ ] **Step 2:定目标分并写清理由**

目标分建议不低于 500(多数出海企业 JD 只写"CET-6"不写分数,但简历上分数是区分度)。写明:目标分 = ___,依据 = ___。

- [ ] **Step 3:把每日一练接进来,设固定投入**

- 每日:20 分钟(复用现有 `!六级英语每日一练` 项目,不新建体系)
- 每周:1 套听力或阅读专项,记录正确率
- 考前 2 周:2 套完整真题,记录总分

- [ ] **Step 4:判据**

`01-六级.md` 里有:三个时间点、目标分、每周记录 ≥ 连续 4 周、考前真题成绩 ≥2 次。**证书拿到后,把成绩回填简历(专门会话)。**

### Task 5.2:西班牙语 B2(以证书为准)

**Files:**
- Create: `语言与行业/02-西语B2.md`
- 复用: `10-Projects/2026-掌握西班牙语B2`(已存在的备考项目)

**Interfaces:**
- Produces: B2 证书;口语能力(计划 3 的 Task 3.7 与面试直接使用)

- [ ] **Step 1:先做考试决策并写理由**

| 选项 | 特点 | 适合场景 |
|------|------|----------|
| DELE B2 | 官方终身有效,考试场次少、出分慢(约 3 个月) | 需要"终身证书"放简历 |
| SIELE | 机考、出分快(约 3 周)、有效期 5 年 | 赶投递窗口、需要快速证明 |

判据:`02-西语B2.md` 里写明选哪个、为什么、报名与考试日期。

- [ ] **Step 2:定备考节奏(复用现有项目,不另起体系)**

- 每日:复用现有西语项目节奏
- 每周:1 次写作 + 1 次口语录音自检
- 考前 4 周:完整模考 ≥2 次,记录四部分得分

- [ ] **Step 3:口语必须过"技术场景"这一关**

自检标准:能用西语讲清 60 秒 L-ink 的工作原理(计划 3 Task 3.7 的产出),且对方能听懂"能量采集"这类概念。**这是本方向语言能力与普通考生的区别。**

- [ ] **Step 4:判据**

① 报名完成;② 模考达到 B2 阈值 ≥1 次;③ 60 秒技术自述录音完成且自评通过。

### Task 5.3:西语技术销售术语库

**Files:**
- Create: `语言与行业/03-西语术语库.md`

**Interfaces:**
- Consumes: 计划 3 的硬件项目(术语要有真实出处)
- Produces: 面试与客户沟通可直接使用的语料

- [ ] **Step 1:按七个场景分类建表**

```markdown
| 中文 | English | Español | 西语例句 | 出处 |
|------|---------|---------|----------|------|
```

七个场景固定为:① 模组与芯片 ② 频段与制式 ③ 功耗与电源 ④ 储能与电力 ⑤ 渠道与销售 ⑥ 报价与合同 ⑦ 物流与付款。

- [ ] **Step 2:每条都要有出处**

出处写清:官方数据手册页码 / 厂商西语官网页面 / 西语行业媒体。**禁止只写"翻译软件"。**

- [ ] **Step 3:优先覆盖面试高频词**

先写会被问到的:module、band、carrier certification、energy harvesting、e-paper、lead time、MOQ、quotation、distributor、after-sales。

- [ ] **Step 4:判据**

① 条目 ≥100;② 七个场景都有;③ 抽查 10 条能口述并造句;④ 每条有出处列非空。

### Task 5.4:出海行业情报库

**Files:**
- Create: `语言与行业/行业情报/<公司>.md`(20 家各一页)

**Interfaces:**
- Consumes: [岗位池](<岗位池.md>)的 20 家公司
- Produces: 面试题 Q17「为什么选我们公司」的弹药

- [ ] **Step 1:每家一页,固定六栏**

```markdown
# <公司名>
- 产品线与主打型号:
- 海外市场与区域划分:
- 主要竞品:
- 最近财报 / 融资要点(带时间):
- 招聘动向(2027 届通道状态):
- 面试可用的三个事实:    <- 必须具体到数字或事件
```

- [ ] **Step 2:"面试可用的三个事实"是硬指标**

反例:"公司发展好、平台大"(面试官一天听几十遍)。正例:"海外营收占比超过 50%,销售区域分为中国/欧洲/北美/亚非拉四区"。

- [ ] **Step 3:判据**

① 20 家各一页;② 每页"三个事实"都有来源;③ 每月更新一次(在文件头记更新日期)。

## 风险与对策

| 风险 | 对策 |
|------|------|
| 技术线挤占语言时间 | 语言是硬证书、且是唯一的筛人条件;每日固定投入不与其他轨道协商 |
| 术语直译出错(面试翻车) | 每条必须有西语一手出处;抽查口述自检 |
| 情报库变成"抄官网简介" | 硬指标:每页三个具体事实,带数字或事件 |
| 考试场次错过窗口 | Task 5.1 / 5.2 的 Step 1 先写死日期,再谈备考 |
