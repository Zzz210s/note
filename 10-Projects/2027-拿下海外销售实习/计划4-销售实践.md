# 计划 4:轨 C · 销售实践(权重最高)

> **给执行者:** 本文件只定义"做什么、做到什么算成、产物放哪"。投递、面试、到岗、发帖由本人执行。
> **上级文档:** [项目说明](<!项目说明.md>) / [实施计划总览](<!实施计划.md>)

**目标:** 在 2027 暑期实习投递之前,拿到**至少一段能写进简历、且能讲出量化结果的销售/外贸实践**。

**为什么这条权重最高:** 海外销售岗的筛选顺序是「英语 → 销售/外贸经历 → 行业理解 → 沟通证据」。技术作品是加分项,销售实践才是入场券。**技术线再漂亮,这一栏空白就过不了简历关。**

**约束:**

- 线下到岗实习优先,校园实践与独立站并行
- 每条经历必须留下**可量化结果**(询盘数、客户数、成交额、触达人数),否则在简历上等于没做
- 与计划 1 的投递台账共用同一套状态口径,不另建体系
- 涉及真实客户时,不泄露对方商业信息;作品集里只写自己做了什么

## 产出物

```
销售实践/
  01-实习投递台账.md      岗位、渠道、状态、跟进(与投递台账口径一致)
  02-到岗实习记录.md      做了什么、量化结果、可讲的故事
  03-校园实践.md          经历与量化结果
  04-独立站实操.md        产品选择、落地页、询盘数据
  05-内容获客.md          文章链接与互动数据
```

### Task 4.1:线下到岗实习(主线,优先级最高)

**Files:**
- Create: `销售实践/01-实习投递台账.md`

**Interfaces:**
- Consumes: [岗位池](<岗位池.md>)、简历三版(专门会话产出)
- Produces: 简历"实习与实践"栏的第一条真实经历

- [ ] **Step 1:确定三类目标岗位(不局限"海外销售"四个字)**

| 类型 | 岗位名举例 | 为什么投 |
|------|-----------|----------|
| 外贸业务 | 外贸业务员 / 外贸跟单 / 跨境电商运营 | 门槛低、量大、能立刻上手真实询盘 |
| 海外销售支持 | 海外销售助理 / Inside Sales / 销售运营 | 与目标岗位同一条职业线 |
| 售前与技术支持 | 售前技术支持 / 技术支持工程师 | 技术背景能直接用上,最贴近"技术型销售" |

- [ ] **Step 2:确定五个渠道并写清各自的动作频率**

公司官网校招页、Boss 直聘、实习僧、牛客、学校就业网/本地外贸公司。**每周至少 3 家投递,记录在台账。**

- [ ] **Step 3:台账口径与计划 1 一致**

状态取值沿用:`已投 / 已读 / 笔试 / 一面 / 二面 / 终面 / offer / 拒 / 无回应`。

- [ ] **Step 4:面试前把"没有销售经验"这个问题练熟**

直接用 `面试题库.md` 的 Q6(你的主武器),并用 4.3 / 4.4 的自主实践作为补充证据。

- [ ] **Step 5:判据**

① 累计投递 ≥15 家;② 至少 1 次真实面试;③ 至少 1 段到岗实习(寒暑假、周末或远程混合均可);④ 实习结束后 24 小时内写完 `02-到岗实习记录.md`(此时记忆最新)。

### Task 4.2:校园实践(并行,零门槛,立刻可做)

**Files:**
- Create: `销售实践/03-校园实践.md`

- [ ] **Step 1:从四类里选一到两个**

校园大使(企业在校内的推广岗)、学生组织外联(拉赞助 = 最真实的销售动作)、校园创业团队、留学生/国际学生接待。

- [ ] **Step 2:外联类实践按"销售动作"记录**

```markdown
| 目标 | 我做了什么 | 结果 | 可量化的数字 |
|------|-----------|------|--------------|
| 某商家赞助 | 打电话 + 上门 + 提案 | 谈成 / 未成 | 金额或触达人数 |
```

- [ ] **Step 3:判据**

① 至少一段经历;② 至少一个量化结果(拉到多少赞助、覆盖多少人、谈成几家);③ 能口述"我怎么说服对方"的完整过程。

### Task 4.3:独立站 / 国际站实操(把"卖"这件事真的做一遍)

**Files:**
- Create: `销售实践/04-独立站实操.md`

**Interfaces:**
- Consumes: `personal-site` / `personal-content` 的建站能力(已有基础设施)
- Produces: 真实访客与询盘数据 —— 面试时"我做过真实获客"的硬证据

- [ ] **Step 1:先选产品,写清选择理由**

| 选项 | 说明 |
|------|------|
| 自研小硬件/工具 | 与 L-ink 或 `pressctl` 之类作品绑定,故事统一 |
| 代理一个真实品类 | 找身边可拿货的品类(如电子配件),做真实报价与询盘 |
| 虚拟服务 | 技术咨询/翻译/建站,门槛最低但销售含量较低 |

- [ ] **Step 2:建英文落地页**

复用 `personal-site` 的 Astro 能力,或单独一个静态页;必须有:一句话价值、产品图/视频、规格表、报价入口、联系方式。

- [ ] **Step 3:跑真实获客动作并记录**

渠道:领英、Reddit、行业论坛、Google 自然搜索、独立站 SEO。记录:访客数、询盘数、回复率。

- [ ] **Step 4:判据**

① 落地页上线(URL 可访问);② 至少 50 个真实访客 **或** 1 条真实询盘;③ 数据与动作写进 `04-独立站实操.md`;④ 有复盘:哪句话有效、哪个渠道无效。

### Task 4.4:英文内容获客实验(与计划 3 共用素材)

**Files:**
- Create: `销售实践/05-内容获客.md`

**Interfaces:**
- Consumes: 计划 3 的 L-ink 实测数据与 demo 视频
- Produces: 真实的海外技术社区互动记录

- [ ] **Step 1:写 2 篇英文内容(选题从已有素材里出,不新造)**

| 选题 | 目标读者 | 投放渠道 |
|------|----------|----------|
| How NFC energy harvesting powers a battery-free e-paper card | 嵌入式工程师 / 硬件爱好者 | Hackaday、Reddit r/NFC、r/embedded |
| What I measured: real numbers from an ST25DV harvesting circuit | 硬件工程师 | dev.to、Reddit、Hackster |

- [ ] **Step 2:记录互动数据(不发完就完事)**

阅读数、评论数、私信数、被转载/引用情况。**评论里出现的真实问题要收集起来** —— 它们是面试题的素材库。

- [ ] **Step 3:判据**

① 发布 ≥2 篇;② 有互动数据记录(哪怕数字很小,也要如实记录);③ 从评论中收集到 ≥3 个真实技术问题。

## 风险与对策

| 风险 | 对策 |
|------|------|
| 到岗实习与学业冲突 | 优先寒暑假;学期内用周末/远程混合;不行就用校园实践 + 独立站顶上 |
| 投递无回应 | 换渠道(官网 / Boss / 实习僧 / 本地公司)、降层级(小公司也投)、让简历先有实践条目再回投大公司 |
| 独立站没人看 | 先做内容获客(4.4)再导流,而不是等自然流量;数据小也如实记录,重点在"我做过完整动作" |
| 实践做了但写不出量化结果 | 事前就定义要记录的数字(询盘数/触达人数/成交额),做完立刻记,不靠回忆 |
