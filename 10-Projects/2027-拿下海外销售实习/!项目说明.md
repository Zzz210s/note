# 2027-拿下海外销售实习

> 属于 `10-Projects\` 项目层(年粒度 · 进阶 · 求职实战)。
> 与「[2026Q4-复刻L-ink智能名片](<../2026Q4-复刻L-ink智能名片/!项目说明.md>)」「[2026-09-搭建RFID点唱机](<../2026-09-搭建RFID点唱机/!项目说明.md>)」串联:那两件硬件作品是本项目技术证据轨的旗舰产出。
> 定位:**技术型海外销售 / 海外售前解决方案**方向,嵌入式为备选。

- **目标:** 拿到 2027 年暑期实习 offer(技术型海外销售 / 海外售前 / 海外技术支持方向),并在此过程中留下可验证的技术与销售证据
- **状态:** 进行中
- **起止:** 2026-09-21 → 2027-08(以 offer 到手为出口,**不设日历节点**,按事件驱动推进)
- **为什么做:** 方向已明确为海外销售为主、嵌入式备选;目标岗位集中在 IoT 模组、AI 硬件、通信设备、储能出海、工业自动化五类企业,这些岗位的 JD 普遍要求"理工科背景 + 英语 + 沟通能力",而本人的组合(软件能力 + 硬件与物联网课程 + 梅西大学海外经历 + 西班牙语)正好命中,但缺两样东西:**一段真实的销售实践**与**拿得出手的技术作品**。本项目就是补这两样。

## 一、验收标准

| 层级 | 指标 | 验收方式 |
|------|------|----------|
| 主目标 | 至少 1 个技术型海外销售/售前方向暑期实习 offer | offer,或至少 3 家进入终面 |
| 投递 | 20 家定向投递(非无差别海投) | 岗位池表逐行有状态 |
| 销售实践 | 1 段销售/外贸相关经历(线下到岗实习优先,校园实践/独立站可并行) | 有可量化结果(询盘量、成交、客户数) |
| 技术证据 | L-ink 复刻出实物 + 英文作品集 2 件 + Linux 内核 upstream commit 至少 1 个 | 实物演示视频、仓库链接、commit 链接 |
| 语言 | 取得英语六级 + 西班牙语 B2 | 证书 |
| 面试 | 能用英语完整讲清一个技术链路(如 NFC 无源取电) | 模拟面试通过 |

**明确不作为指标:GitHub star 数、徽章数量。** 理由:海外销售岗的筛选逻辑是"英语 → 销售/外贸经历 → 行业理解 → 沟通证据",star 与徽章对录用几乎无影响;盯着它会挤占主线时间。star 与徽章只作为副产品观察。

### 时间窗口(关键)

2027 届暑期实习**提前批已开跑**:宝时得 2027 届暑期提前批(海外销售支持岗要求"本科 + 英语六级 + 理工科优先")、优刻得 2027 海外销售运营 / 海外市场实习、正浩 2027 届研发提前批(2026-07 启动)、安克 2027 届全球校招(2026-08 发布)。**结论:现在是投递窗口,不是准备期。**

### 两张独有杠杆

1. **西班牙语 + 拉美/西语市场红利**:西语销售岗在储能、光伏、消费电子出海大量放量(菲利斯太阳能 15-30k·14薪;杭州多加古巴光伏底薪 8-12k + 出差补贴 3k + 1% 提成;厦门 12-18k·16薪;北京国际销售英语/西语 15-30k)。华为春招小语种方向明确"西班牙语优先,全球派遣墨西哥/哥伦比亚/秘鲁"。中拉贸易 2025 破 5000 亿美元,拉美电商 2026 预计 2000 亿美元。
2. **能自己写代码的销售**:目标岗位面试会往技术里问(移远 AI 硬件销售、亿联海外售前、海康海外解决方案),技术作品的价值在于"客户的技术问题我自己能验证",而非 star 数。

## 三、四轨结构(每周 3-5 小时)

```text
轨 A 求职材料    新构   三版简历、岗位池、面试题库、投递台账
轨 B 技术证据    新构   L-ink 旗舰 + Linux 内核线 + 英文作品集
轨 C 销售实践    新构   线下到岗实习(优先) + 校园实践/独立站
轨 D 语言与行业  重塑   目标:六级 + 西语 B2;配套术语库与行业情报库
```

### 轨 A 求职材料(新构)

- 三版简历:IoT 模组与方案商 / AI 硬件与消费电子 / 工业自动化与机器人
- 岗位池表:公司 × 岗位 × 硬性要求 × 投递渠道 × 状态
- 面试题库(技术型销售向):"用非技术语言解释 NFC 无源取电""讲一次你解决技术问题的经历""你懂哪些协议、怎么跟研发对话""你为什么不做纯研发"
- 投递台账与跟进节奏
- **推进原则:简历 v1 一出当天就开始投,不等作品集齐** —— 用真实面试反馈迭代材料

### 轨 B 技术证据(新构)

**旗舰(硬件):L-ink 智能名片复刻** —— 实物 + 英文 README + 原理框图 + demo 视频 + 实测数据(能量采集输出电压/电流、刷新功耗)。实测数据回帖到上游 7,646 star 的 `peng-zhihui/L-ink_Card`(该仓库有真实提问如"能量采集能输出 3.3V 的电压吗",上游 2021-01 后停更,适合用实测数据回答而非提 PR)。

**Linux 内核线(推进顺序:练手 → 必做 → 长线):**

| 选项 | 内容 | 核实到的事实 | 门槛 / 对口度 |
|------|------|--------------|---------------|
| B-3 练手 | 第一个内核补丁(小 cleanup 或 IIO 相关),打通提交链路 | 内核新手标准入口(kernelnewbies / Bootlin 有完整教程) | 低;通用 |
| B-1 必做 | 给 `qmi_wwan.c` / `option.c` 加 IoT 模组设备 ID,或修真实缺陷;配套用户态模组排查 CLI | 上游这条线极活跃:2026-09-07 合并 `net: usb: qmi_wwan: add Quectel RG660QB`,2026-09-02 Compal、2026-08-17 Telit、2026-05-21 MeiG SRM813Q | 低、可合并;**直接对口移远/广和通/美格/星纵物联** |
| B-2 长线旗舰 | 给 ST25DV-I2C 动态 NFC 标签写 Linux 内核驱动 | 已核实:**mainline `drivers/nfc` 无 st25dv**;ST 官方只有用户态驱动(STSW-ST25DV009);第三方 out-of-tree 驱动仅 14 star、2022 年后停更 | 高、周期长;与 L-ink **共用同一颗芯片**,可讲成完整链路:手机 NFC → ST25DV 取电 → MCU 刷屏,Linux 侧驱动读同一颗芯片 |

### 轨 C 销售实践(新构,权重最高)

- **主线:线下到岗实习**(销售 / 外贸 / 售前 / 技术支持皆可,小公司也认)—— 唯一显著提高简历通过率的东西
- 并行:校园实践 / 独立站(阿里国际站、独立站内容与询盘实操)
- 并行:英文内容获客实验 —— 用 L-ink 技术链路写英文文章 / 视频,发 Hackaday、Reddit(r/NFC、r/embedded)、dev.to,记录真实互动(阅读、评论、私信询盘)

### 轨 D 语言与行业(重塑)

- 语言目标不变:**英语六级 + 西班牙语 B2**(以证书为准)
- 配套产出一:**西语技术销售术语库与商务话术**(模组 / 频段 / 储能 / 渠道 / 报价谈判),直接用于客户沟通与面试
- 配套产出二:**出海行业情报库**(目标公司产品线、海外市场分布、竞品、财报与融资要点)

## 四、推进顺序(事件驱动,无日历节点)


## 五、度量与风险

**只记四个数**:投递数、面试数、PR 被合并数、实习是否到手。每月复盘一次,写进本文件「复盘 / 出口」。

**风险与对策:**

| 风险 | 对策 |
|------|------|
| 内核补丁被打回 | 从设备 ID 类小补丁起步,先学会内核 review 文化与邮件格式 |
| L-ink 采购或焊接卡住 | 用「[2026Q4-复刻L-ink智能名片](<../2026Q4-复刻L-ink智能名片/!项目说明.md>)」已写的三轨道方案(完整复刻 / 开发板原型 / 深度解读) |
| 海投无回应 | 降低目标层级、换渠道(牛客 / 实习僧 / 公司官网 / Boss)、加投中小出海公司 |
| 只做技术不出成果,销售经历为零 | 轨 C 权重高于轨 B:每月至少推进一次实习投递或实践动作 |

## 决策记录(为什么不那样做)

- **不把 star 数与徽章作为指标**:对海外销售岗无筛选效力,只在项目真被需要时自然发生。
- **不用 `netscope` / `ai-session-hub` 当旗舰作品**:面向开发者、与目标行业(IoT / 消费电子 / 通信)不搭,面试官看不懂也不关心。
- **四条轨全部新构或重塑**:不把已有的西语 B2、六级英语项目当作现成投入复用,语言目标仍以证书为准,但要另出术语库与情报库。
- **不设阶段式日历时间轴**:方向明确后立即海投,材料与作品边投边迭代。
- **轨 C 权重高于轨 B**:销售/外贸经历是简历通过率的主导因素,技术作品是加分项。
