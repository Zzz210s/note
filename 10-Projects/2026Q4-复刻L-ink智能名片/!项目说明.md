# 2026Q4-复刻L-ink智能名片

> 属于 `10-Projects\` 项目层(季度粒度 · 进阶 · 硬件复刻)。RFID 应用双项目之二,承接「2026-09-搭建RFID点唱机」,合计窗口 2026-09-01 → 2026-12-01。
> 来源:开源项目 peng-zhihui/L-ink_Card(GitHub stars:约7.6k,STM32 C 固件 + Altium 硬件工程)——稚晖君的电子墨水屏 NFC 智能名片:手机 NFC 场无线取电,驱动 STM32L051 刷新墨水屏,全程无电池。
> 定位:点唱机项目是"用 RFID",本项目是"懂 RFID"——吃透 NFC 能量采集、ISO 15693 协议、无源供电设计与超低功耗嵌入式。

- **目标:** 吃透 L-ink Card 的"NFC 取电 → 唤醒 MCU → 刷墨水屏"无源链路,按三条轨道之一落地(完整复刻 / 开发板原型 / 深度解读),并完成一处自己的定制
- **状态:** 未开始
- **起止:** 2026-10-16 → 2026-12-01
- **为什么做:** 它把 RFID 最容易被忽视的能力(射频能量采集)玩成了产品,一张卡覆盖 NFC 通信、无源取电、低功耗设计、墨水屏驱动、PCB 制作——嵌入式毕设考察点一网打尽
- **验收标准:**
  1. 能画框图讲清完整链路:手机 NFC 电磁场 → ST25DV 能量采集 → 供电唤醒 STM32L051 → 驱动墨水屏刷新(讲不清这条链不算完成)
  2. 按所选轨道验收:
     - 轨道A 完整复刻:实物点亮——手机贴近触发墨水屏刷新,NFC 读出标签内容,并完成至少一处显示定制
     - 轨道B 开发板原型:STM32L0 开发板 + 墨水屏模块 + ST25DV 模块跑通"读 NFC + 刷屏"主干
     - 轨道C 深度解读:固件本地编译通过 + 产出逐模块源码解读文档(硬件/固件/APP 三层)
  3. 沉淀笔记完成(NFC 协议族谱、能量采集、STM32L0 低功耗、墨水屏驱动),文件夹移入 40-Archive
