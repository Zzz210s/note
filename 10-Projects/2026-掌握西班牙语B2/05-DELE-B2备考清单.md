# DELE B2 备考清单

> DELE B2 通过标准:总分 100,通过线 60,且阅读理解 / 听力理解 / 书面表达 / 口语表达四个测试组(pruebas)每组都需 apto(即每组 >= 60%)。
> 备考书:《Preparación al DELE B2》(含语法解析 + 真题 + 模拟)。

## DELE B2 结构

| 测试组 | 满分 | 内容 | 时长 |
|---|---|---|---|
| 阅读理解(Comprensión de lectura)| 25 | 选择题为主,含多篇阅读 | ~70 min |
| 听力理解(Comprensión auditiva)| 25 | 选择题为主,含多段录音 | ~40 min |
| 书面表达(Expresión escrita)| 25 | 2 个任务:任务1 综合任务(读+听后写作);任务2 选项写作(信件/评论/博客等)| ~60 min |
| 口语表达(Expresión oral)| 以官方为准(近年权重调高,含 Tarea1-3)| Tarea1 读图/数据后口头报告;Tarea2 与考官对话;Tarea3 讨论对话 | ~20 min |

> 注:各组分值以官方当期考纲为准(口语组权重近年调高),核心目标不变:四组各 apto。

## 各部分策略

### 阅读理解
- 限时训练,先题后文定位关键词。
- 积累真题阅读生词进积累本。
- 注意虚拟式 / 条件式 / 被动 / 间接引语在长难句中的识别(呼应 Q3 语法)。

### 听力理解
- 每日泛听(Destinos / Extra / 现西 MP3)打底。
- 真题听力精听:第一遍做题,第二遍看文本对照,第三遍盲听。
- 注意西语连读、吞音(但不纠结口音差异,聚焦语义)。

### 书面表达
- 任务1(综合):读 1 篇 + 听 1 段后写综述,练信息整合与衔接。
- 任务2:练信件(formal/informal)与评论,背正式书面连接词与套语。
- 每周写 1 篇,找语伴/老师批改(italki 可选),或自检对照范文。

### 口语表达
- Tarea1:练读图/读数据后 1-2 分钟口头报告,影子跟读打底。
- Tarea2:练与考官对话,练虚拟式得体表达观点(creo que / no creo que / me parece importante que)。
- Tarea3:练讨论对话,练论辩与反驳连接词。
- Q3 起每周自录音 1 次,回放纠错;可选 italki 每周 1 次 30 min。

## Q4 备考周序(W40-52)

| 周次 | 内容 |
|---|---|
| W40 | 备考书导读 + DELE B2 全真结构拆解 + 语法查漏(据 Q3 末自测)|
| W41 | 阅读专项轮训 + 真题 1 套阅读 |
| W42 | 听力专项轮训 + 真题 1 套听力 |
| W43 | 写作专项 + 真题 1 套写作(任务1+任务2)|
| W44 | 口语专项 + Tarea1-3 单练 + 自录音 |
| W45 | 真题全真模考 1 套(全套计时)+ 错题分析 |
| W46 | 据模考弱项回炉 + 真题 1 套(阅读+听力)|
| W47 | 真题 1 套(写作+口语)+ 批改 |
| W48 | 真题全真模考 2 套 + 错题分析 |
| W49 | 据模考弱项回炉 + 口语对练强化 |
| W50 | 真题全真模考 3 套 + 错题分析 |
| W51 | 最后查漏 + 口语套语与写作模板固化 |
| W52 | 冲刺周 + 轻量复习 + 考前状态调整 |

## 通过判定(年闸)

- Q4 末(W50-W52)连续 2 套全真模考:总分 >= 60 且四组各 apto -> 视为达 DELE B2 通过线。
- 不达 -> 续刷真题至通过(用冗余时间)。
