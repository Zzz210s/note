## ③ 课文(现代西班牙语 第 1 册 第 7 单元 · II. Comprar por Internet)

> 手写笔记转写(图片:`30-Resources/.../08-每日笔记/2026-09-06/`)。承接 09-05 例句 7-11,本日整理课文 II 的例句 13-16 及配套语法点(前缀/servir 变位/Acaso/Ni/情态助动词)。

**13. ¿Acaso puedes hacer los trabajos de casa y al mismo tiempo ir a comprar a la tienda?(难道你能一边干家务,一边同时去商店买东西?)**
- **acaso**(①):副词,意为"难道 / 也许"。acaso + 疑问句表**反问**,相当于英语 "by any chance / perhaps"。例:¿Acaso no lo sabías?(难道你不知道吗?)
- **acaso**(②):用于**假设/不确定**的陈述句,表"或许 / 万一",≈ quizás(也许)/ tal vez(可能)。例:Si acaso viene, avísame.(万一他来了,告诉我。) / Lleva un paraguas por si acaso.(带把伞以防万一。)
- al mismo tiempo:同时(时间)。
- a la vez:同时(= at once)。
- mientras tanto:在那期间,与此同时。
- **servir 变位**(e→i 型,书上未列全,补全表):

| servir(服务,有用) | |
| --- | --- |
| yo sirvo | nosotros servimos |
| tú sirves | vosotros servís |
| él/ella sirve | ellos/ellas sirven |

- **前缀 un- / re- / de- 与程度**:`v+ 前缀动词` 表动作/状态程度的增减;cada vez + 比较级表"越来越"，如 cada vez más(越来越多)。

**14. Con el Internet no necesitas ir a la tienda ni preparar la comida.(有了互联网,你既不需要去商店,也不需要做饭。)**
- **ni** = 连接词,表"也不,甚至不",相当于英语 "nor"。
- **ni...ni...**:既不…也不…(全否定)。例:No come carne ni pescado.(他既不吃肉也不吃鱼。)
- **ni siquiera**:甚至不 / 连…都不。例:No habla ni escucha.(他既不说话也不听。);Ni siquiera lo intentó.(他甚至没尝试一下。)

**15. En realidad, ahora, más y más gente compra por Internet porque es un servicio que ofrece muchas ventajas y sirve para muchas cosas.(事实上,现在越来越多的人在网上购物,因为它是一项提供许多好处、对许多东西都有用的服务。)**
- **gente vs persona**(④):
  - gente:f. 不可数名词,表"人们 / 人群",只接**单数**谓语。例:la gente compra(人们购买)。
  - persona:f. 可数名词,表"个人 / 人",有单复数(una persona / dos personas)。
- **cosa vs ventaja**(③):
  - cosa:f. 东西,事物(可数)。
  - ventaja:f. 优势,好处。
- **ofrecer**:v. 提供,给予(= offer)。
- **ahorrar**:v. 节省,节约(ahorrar tiempo 节省时间)。
- **porque / por / como / ya que / pues**(⑤ 因为):
  - porque = 因为(原因,"因为",合写,连词,中性)。
  - por = 因为 / 由于(介,后可接名词,表原因或用于"por + 名词"如 por eso 因此)。
  - como = 因为(常用于句首,表理由,后接句)。
  - ya que / puesto que = 既然,因为(连接,"既然…"表既成事实)。
  - debido a / a causa de = 由于,因为(介词短语,后接名词)。

**16. ¿Quieres comprar una mesa, una silla, una botella de vino, una revista?(你想买一张桌子、一把椅子、一瓶红酒、一本杂志吗?)**
- **情态/半助动词 + 动词原形**(① 总表)(这些动词后接**动词原形** infinitivo):

| 类别 | 动词 | 含义 |
| --- | --- | --- |
| 意愿与计划 | querer + 原形 | 想要,打算 |
| | pensar + 原形 | 打算,计划 |
| | desear + 原形 | 渴望,希望 |
| 能力与许可 | poder + 原形 | 能够,可以 |
| 义务与必要性 | deber + 原形 | 应该做(强调责任) |
| | necesitar + 原形 | 需要做 |
| | tener que + 原形 | 不得不做(客观需要) |
| | hay que + 原形 | 必须做(泛指,没人称) |
| 习惯 | soler + 原形 | 通常,习惯于 |
