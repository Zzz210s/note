## 一、环境与工具

- **VS Code + 插件** `LeetCode.vscode-leetcode`(插件市场安装;需本机 Node.js)
- **登录配置**:`settings.json` 里 `leetcode.endpoint` 设 `leetcode` 或 `leetcode-cn`;**用 `leetcode.cn` 账号可正常登录**;`leetcode.com` 节点插件当前有官方已知登录问题,可用 CN 账号或 Cookie 兜底
- **主语言**:选一门(建议 C++ / Python),笔记与代码都用它,减少切换成本
- **笔记仓库**:本库 `F:/0-Note`(远程 `github.com/Zzz210s/note`),模块已在 `01-算法`、`00-MOC/算法.md`

## 二、每日流程(一天一题)

```
① 选题   → 按专题+难度路由取当天一题(未开始先 Easy)
② 独立思考 → 限时约 25min 先自己写(想到哪记到哪,不准立刻看题解)
③ 卡住   → 看 LeetCode 官网标签/提示/题解,重点记"卡在哪""错思路"
④ 写笔记  → 复制 90-Templates/20-笔记正文模板.md → 20-Areas/01-算法/{题目}.md
            (frontmatter: type/tags/status/date/difficulty/source/review)
⑤ 登记索引 → 在 00-MOC/算法.md 对应专题行下加一行链接
⑥ 分享    → git add / commit / push(每道题一条 commit,标题含题号+专题)
```

> 📋 **每日笔记模板**(可直接跳转)→ [`90-Templates/算法-每日笔记模板.md`](<../../90-Templates/算法-每日笔记模板.md>)

- 每题笔记要点(照 `90-Templates/20-笔记正文模板.md` 骨架):题意(自己话)→ 直觉与试错 → 核心思路 → 代码 → 复杂度 → 同类题 → 复习记录
- **踩坑分类**(照 `90-Templates/算法-每日笔记模板.md` 第③段):先标“出在解题哪一步”(读题/思路/边界/实现/复杂度),再标可复用度 🔁通用(进专题防坑清单)/ 📄个题(随题即可)
- 每天做 **1 题**;做不出也没关系,当天也交"错题复盘"笔记(记录思考与卡点),同样 push——坚持比数量重要

## 三、刷题路线(由简及难 · 参考代码随想录顺序)

| 阶段 | 专题 | 起步难度 | 出题主题 |
|------|------|---------|---------|
| 1 | 数组 | Easy | 双指针、前缀和、二分、滑动窗口 |
| 2 | 链表 | Easy | 指针操作、哑节点、反转/合并 |
| 3 | 哈希表 | Easy | map/set 去重、两数之和 |
| 4 | 字符串 | Easy | 处理、反转、计数 |
| 5 | 栈与队列 | Easy→Med | 单调栈、括号匹配、单调队列 |
| 6 | 二叉树 | Med 起步 | 前中后序/层序、DFS/BFS、递归 |
| 7 | 回溯 | Med | 组合/排列/子集 |
| 8 | 贪心 | Med | 区间、分配 |
| 9 | 动态规划 | Med | 背包、线性 DP、状态机 |
| 10 | 图论 | Med→Hard | BFS/DFS、最短路径、并查集(进阶) |

**推进策略**
- 前 2 周:只刷 Easy,覆盖 数组/链表/哈希/字符串,建立手感与模板
- 之后:栈队列、二叉树 用 Easy+Medium
- 再往后:回溯/贪心/DP 以 Medium 为主;Hard 少量、只挑经典(DP/并查集)
- 每个专题结束:写一篇**专题总结**(把该专题通用套路固化),并**把该专题所有 🔁通用踩坑汇总成『XX 专题防坑清单』**;再进下一专题
