- **目标:** 每天完成三件套——**背通读 1 篇六级作文 + 听力精听 1 段 + 作文仿写 1 段**,累计提升写作与听力到稳过六级
- **状态:** 未开始(框架已定)
- **起止:** 起始日 → 考试前(暂定 2026-12 六级)
- **验收:**
  - 累计**背熟 5~8 篇**范文(覆盖图画 / 图表 / 提纲三类),能脱口而出
  - 累计**精听 30 段**真题、跟进"模糊词清单"
  - 累计**仿写 30 段**,用上今日提取的高分句式
  - 每天一条 commit 推 GitHub 分享

## 一、方法依据(联网调研:新东方 / 沪江 六级备考方法)

- **听力**:精听 + 泛听结合。精听是核心(约 30 分钟/天):完整听抓主旨 → 逐句暂停听写 → 对照原文标**连读/弱读** → 逐句跟读模仿 → 裸听;基础弱先逐句精听,后期转"抓关键"。听力词汇要"**听到即反应**",建"模糊词清单"。
- **背诵/写作**:背 5~8 篇**代表范文**,背到脱口而出。方法:**先理解** → 标段落主旨/论证手法 → 提关键词提纲 → **分段背诵** → **大声朗读**(视听口多重记忆)→ **默写**检验("背了不一定会写")。提取高分**句式**下来**仿写**,才是得分关键。

## 二、每日流程(三件套)

> 📋 **每日模板**(可直接跳转)→ [`90-Templates/六级-每日笔记模板.md`](<../../90-Templates/六级-每日笔记模板.md>)

### ① 背诵通读(≈20min)— 用 `90-Templates/六级-每日笔记模板.md`
1. 选 1 篇真题范文(图画 / 图表 / 提纲三类轮换)
2. 先理解:分段标主旨与论证手法
3. 大声朗读 2~3 遍(调动视听口)
4. 按关键词提纲**复述**一遍
5. 睡前**默写**关键句 / 逐段串联

### ② 听力精听(≈30min)— 用同一模板
1. 预读选项 → 完整听抓主旨
2. 逐句**暂停听写**
3. 对照原文标**连读 / 弱读**等语音现象
4. 逐句**跟读模仿** → 裸听
5. 记入"**模糊词清单**"(看着认识、听时不反应的词)
- 碎片时间**泛听**当背景音(不要求每句听懂)

### ③ 作文仿写(≈20min)— 用同一模板
1. 从今日范文 / 听力里**提取 1~2 个高分句式**
2. 按今日话题**仿写 1 段**
3. 标出用到的**模板 / 逻辑连接词**

### ④ 复盘与提交
- 记录今日收获 / 卡点 → `git commit`(标题含日期) 推 GitHub
