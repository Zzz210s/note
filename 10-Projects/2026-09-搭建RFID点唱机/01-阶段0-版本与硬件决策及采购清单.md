# 阶段 0:版本与硬件决策及采购清单

> 时间窗 2026-09-01 → 09-07(等快递的同时推进预习)。上游依据:`!项目说明.md` 的任务清单。

## 一、版本决策(2026-09-01 调研完成)

| 候选 | 说明 | 结论 |
| --- | --- | --- |
| **V2 classic** | 官方默认;本地音乐 / 播客 / 网络电台齐全 | **选定** |
| Spotify 版 | 需要 Premium 账号 | 不选 |
| V3 | 尚缺电台 / 播客,不满足验收标准 | 否决 |

## 二、硬件清单(合计预算约 300~600 元)

| 读卡器 | USB 读卡器(免接线最稳)/ MFRC522 模块(走 GPIO 更练手),二选一 | **RC522 模块** | | | 待下单 |

## 三、决策记录

- **为什么装 classic 而不是 Spotify 版**:后者需要 Premium 账号,官方默认路线也是 classic。
- **为什么否决 V3**:电台 / 播客能力缺失,达不到"刷卡即播 + Web 界面管理"的验收标准。
- **为什么选 RC522 模块而不是 USB 读卡器**:走 GPIO 更练手,配合树莓派 40 引脚图预习 SPI 接线。
