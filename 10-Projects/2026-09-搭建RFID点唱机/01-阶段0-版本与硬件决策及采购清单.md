# 阶段0 调研:版本与硬件决策 + 采购清单

> 2026-09-01 完成的调研。对应 !项目说明.md 阶段0 前两项任务。结论先行:**装 V2 classic 版 + RC522 读卡器 + Pi 4B(或二手 3B+)**。

## 一、版本决策:V2 classic

### 背景一新发现:项目有 V2/V3 两代

读官方 README(2026-08 仍在更新,stars 约 1.8k)发现比预期多一层选择:

- **V2(master 分支)**:经典稳定版,PHP + Python + Shell,一键安装脚本 + Wiki 文档齐全,但已进入维护模式(只修不加新功能)
- **V3(future3 分支)**:官方说"即将成为默认版",重构为纯 Python 核心 + 插件系统 + 新 Web 应用,仍在开发中

### 为什么选 V2 classic

1. **V3 功能还不够,卡验收标准**:官方 status.md 原话,当前 V3 "playing music from local folders via RFID trigger. We also built a new WebUI",而 streams(网络电台)、podcasts(播客)、Spotify **尚未集成**。本项目验收标准第 2、3 阶段明确要求配网络电台和播客 RSS,V3 直接不满足
2. **V2 文档生态最全**:完整 Wiki(INSTALL/MANUAL/Troubleshooting-FAQ/Complete Install Guide),踩坑能搜到解法;V3 文档还在建设中
3. **classic 版无需 Spotify Premium**,免账号门槛
4. 维护模式对本项目无影响:要的是"稳定跑通 + 定制",不是追新

> 若之后 V3 正式发布且功能补齐,可以作为复盘时的"升级实验",不影响本项目验收。

## 二、读卡器决策:RC522(GPIO/SPI)

笔记原话"二选一",现定:**RC522 模块**。

| 对比项 | RC522 模块 | USB 读卡器(HID) |
|---|---|---|
| 接线 | SPI 走 GPIO,需杜邦线 8 根 | 即插即用,免接线 |
| 频段/协议 | 13.56 MHz,MIFARE Classic(ISO 14443A) | 多为 125 kHz EM4100(README 推荐款即此) |
| 与第二项目衔接 | 同 13.56 MHz,可与 L-ink 的 ST25DV(ISO 15693)做同频段不同协议的对照,学习路线连贯 | 125 kHz 与后续项目无交集 |
| 练手价值 | 高:SPI、GPIO、40 引脚图都要碰 | 低:当成键盘输入设备 |
| 价格 | 套装约 10~20 元(常含白卡+钥匙扣) | 约 30~60 元 |
| 官方支持 | components/rfid-reader/RC522/README.md 专门文档 | 安装时自动识别 |

选 RC522 的核心理由:双项目串联设计里,点唱机承担"用 RFID"并铺一遍硬件基础(SPI/GPIO/引脚),这些恰好是 L-ink 项目"懂 RFID"的前置。免接线的便利换不来学习价值。

> 卡片配 RC522 买 **MIFARE Classic 1K**(白卡/钥匙扣/圆形贴纸各来点,贴纸可贴物品上玩)。

## 三、树莓派型号决策

官方 V2 README 列 3B/4/Zero WH 均可;V3 文档顺带提到 Pi 2/3/Zero 2 够用,Pi 4/5 属"过剩"。

- **方案A(推荐,全新)**:Pi 4B 2GB,约 300 元。性能余量大,后续能复用做别的项目
- **方案B(省钱,二手)**:3B+ 二套约 120~180 元。跑 V2 classic 完全够
- 不推荐:Pi 5(贵,过剩)、Zero/Zero 2(音频输出不便:需 USB/蓝牙转接,首配折腾)

### 下单前自查

- [ ] 电脑能读 microSD(或已含读卡器)
- [ ] 家里 WiFi 是 2.4GHz(Pi 3B+/4 的 2.4G 都稳,只开 5G 的路由器需注意)
- [ ] 有一首以上的测试音乐文件
- [ ] RC522 排针是否预焊(没烙铁就买焊好排针或免焊款的)

## 五、预习要点(等快递期间)

1. **烧录**:Raspberry Pi Imager 下载、选择 Raspberry Pi OS(64 位)、自定义设置里预配 hostname/用户/WiFi/SSH——烧完开机即无屏联网,这就是 headless
2. **SSH 连接**:Windows 用 PowerShell `ssh 用户名@raspberrypi.local`(或路由器查 IP);mDNS 不通就插网线
3. **SPI 接线图**(RC522 -> Pi 40pin):SDA->CE0(24)、SCK->SCLK(23)、MOSI->MOSI(19)、MISO->MISO(21)、IRQ->悬空、GND->GND(6)、3.3V->3V3(1)。RC522 只吃 3.3V,接 5V 会烧
4. **Linux 三件套**:`systemctl start/stop/status`、`journalctl -u 服务名 -f`、`lsusb`/`lsmod`/`dmesg | tail`
5. 官方 Wiki 通读顺序:INSTALL -> MANUAL(Register cards / Card control / Web streams / Podcasts) -> Troubleshooting-FAQ
