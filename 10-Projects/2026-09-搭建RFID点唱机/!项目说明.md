# 2026-09-搭建RFID点唱机

> 属于 `10-Projects\` 项目层(月粒度 · 入门 · 部署实操)。RFID 应用双项目之一,与「2026Q4-复刻L-ink智能名片」串联,合计窗口 2026-09-01 → 2026-12-01。
> 来源:开源项目 [MiczFlor/RPi-Jukebox-RFID](https://github.com/MiczFlor/RPi-Jukebox-RFID)(GitHub stars:约1.8k,PHP + Python + Shell)——树莓派 Phoniebox 刷卡点唱机:刷 RFID 卡触发播放本地音乐/播客/网络电台,带 Web 管理界面。安装 Wiki:[INSTALL](https://github.com/MiczFlor/RPi-Jukebox-RFID/wiki/INSTALL) / 使用手册:[MANUAL](https://github.com/MiczFlor/RPi-Jukebox-RFID/wiki/MANUAL)。
> 定位:把「Linux + RFID 硬件 + 开源部署」串成一个拿得出手的实体作品(课设/简历/演示均可)。

- **目标:** 在树莓派上从零部署 RPi-Jukebox-RFID,跑通"刷卡即播",并完成至少一处自己的定制
- **状态:** 进行中(阶段0 调研完成,待采购下单)
- **起止:** 2026-09-01 → 2026-10-15
- **为什么做:** 部署级项目最锻炼"读文档 → 采购 → 最小系统 → 跑通 → 定制"的完整链路,且产出实物,成就感与说服力都强
- **验收标准:**
  1. 刷卡 ≤3 秒出声,再刷一次停止;Web 界面能管理卡片与音频文件夹
  2. 能讲清整体架构与"卡号 → 音频文件夹"的映射机制(讲给人听或写成笔记)
  3. 至少完成一处定制(功能卡 / Web 界面文案样式 / 快捷脚本,任选其一)
  4. 踩坑记录与沉淀笔记完成,文件夹移入 40-Archive
