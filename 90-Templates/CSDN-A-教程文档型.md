## 发布方式(决定语法是否生效,务必先看)

CSDN 有两类编辑器,选错会导致**全部 Markdown 语法原样显示**(标题的 `#`、引用的 `>`、加粗的 `**`、表格的 `|`、代码块的反引号都变成可见的纯文本,不渲染):

- **Markdown 编辑器**(正确):新建文章时编辑器选 Markdown 编辑器,把下面骨架**整段粘贴进源码模式**,`#` `>` `**` `|` ``` ``` ``` ``` ``` 等才会被正确渲染成标题/引用/加粗/表格/代码块。
- **富文本 / HTML 编辑器**(错误):正文会存成 `<p>` 段落,Markdown 符号被当普通文本,CSDN 页面 `content_views` 的 class 是 `htmledit_views` 而非 `markdown_views`--这就是"语法不对"的根因。

**一句话:发布前确认编辑器是 Markdown 编辑器、且切到源码模式,再粘贴。**

完整语法见 [`CSDN-Markdown语法速查.md`](<CSDN-Markdown语法速查.md>)(CSDN 特有语法 `==高亮==` `H~2~O 下标` `2^10^ 上标` 注脚 定义列表 mermaid 图 等)。

下面 `<!-- -->` 注释是写作提示,Markdown 源码模式粘贴后 CSDN 不显示,可保留;`@[toc]` 是 CSDN 目录占位符,勿删。
