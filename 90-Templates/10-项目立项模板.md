# 10-Projects 项目立项模板

> **属于哪层:** `10-Projects\` 项目层。使用时存为 `10-Projects\{目标}-{截止日期}\`,如 `10-Projects\掌握Markdown-2026Q4\`。
> **作用:** 有**明确目标 + 截止日期**的学习/做项目。一个文件夹承载整个项目,完成后整个移入 `40-Archive`。
> **要点:** 项目要有"做完"的概念(有截止),这是它和 20-Areas"长期领域"的根本区别。任务清单用 `- [ ]` 可勾选。

## 项目封面
- **目标:** 一句话说清要做出什么(可验收)
- **状态:** 进行中 / 已完成 / 搁置
- **起止:** 开始日期 → 截止日期
- **为什么做 / 验收标准:** 做完怎么算"成了"

- [ ] 任务二

## ▼ 填充后长这样(示例:学习 Markdown)

```markdown
# 掌握Markdown-2026Q4

- **目标:** 按菜鸟教程(runoob.com)学完 Markdown 核心语法,能写出结构化文档与 GitHub README
- **状态:** 进行中
- **起止:** 2026-10-01 → 2026-12-31
- **验收:** 用 Markdown 写出一份含标题/列表/表格/代码块/图片/链接/任务列表的完整文档
