# 10-Projects 项目立项模板

> **属于哪层:** `10-Projects\` 项目层。使用时存为 `10-Projects\{目标}-{截止日期}\`,如 `10-Projects\博客上线-2026Q4\`。
> **作用:** 有**明确目标 + 截止日期**的学习/做项目。一个文件夹承载整个项目,完成后整个移入 `40-Archive`。
> **要点:** 项目要有"做完"的概念(有截止),这是它和 20-Areas"长期领域"的根本区别。任务清单用 `- [ ]` 可勾选。

## 项目封面
- **目标:** 一句话说清要做出什么(可验收)
- **状态:** 进行中 / 已完成 / 搁置
- **起止:** 开始日期 → 截止日期
- **为什么做 / 验收标准:** 做完怎么算"成了"

- [ ] 任务一
- [ ] 任务二

## ▼ 填充后长这样(示例:个人博客上线)

```markdown
# 博客上线-2026Q4

- **目标:** 用 Hexo + GitHub Pages 上线一个可访问、可写作的个人博客
- **状态:** 进行中
- **起止:** 2026-10-01 → 2026-12-31
- **验收:** 域名 blog.xxx.com 能打开,已发 3 篇技术笔记

## 任务清单
- [x] 选定框架 + 本地跑起
- [x] 选主题 + 写第一篇草稿
- [ ] 推送 GitHub Pages + 绑定域名
- [ ] 接入 nginx / CDN

## 沉淀的知识(成品在 20-Areas)
- [使用Hexo搭建博客](<20-Areas/CodeStudy/网站/使用Hexo搭建博客.md>)
- [域名与DNS](<20-Areas/CodeStudy/系统/网站/域名与DNS.md>)

## 踩坑记录

## 复盘 / 出口
```
