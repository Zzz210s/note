# 使用 Hexo 搭建博客

> 本笔记是 `90-Templates/00-MOC模板.md` 提到的网站 MOC 下的成品;由《博客上线》项目提炼而来。

## 一句话本质
用 Markdown 写文章,Hexo 生成静态 HTML,推到 GitHub Pages / 任意静态托管即可访问。

## 核心内容(用自己的话)
- 选型:静态博客(Hugo/Hexo) vs 动态(WordPress)——个人博客无后台需求,静态更快更省
- 工作流:写 md → `hexo g` 生成 → `hexo d` 部署
- frontmatter 决定标题/标签/发布时间

## 为什么这么写 / 权衡
- 选 Hexo 而非 WordPress:没有服务端数据库,部署简单、免维护,代价是交互(评论/后台)弱
- 中文文件名会 404 → permalink 配 `:title/` 强制 URL 化

## 坑与最佳实践
- 主题升级前先备份 `themes/` 下的改动
- 域名 + CNAME 文件一起提交,避免每次部署丢了自定义域名
