# Markdown 语法

> 本笔记由《掌握Markdown》项目提炼而来;内容整理自菜鸟教程(runoob.com)。

## 一句话本质
用 `#`、`*`、`|` 等直观符号写纯文本,再转换成 HTML/PDF/Word。易读易写、版本控制友好。

## 核心内容(用自己的话)
- 标题:`#` 表示 1~6 级,`#` 与文字间要有空格且位于行首;`=` 一级、`-` 二级
- 列表:无序 `*`/`+`/`-` + 空格;有序 `1.`;嵌套靠缩进;任务列表 `- [ ]` / `- [x]`
- 表格:`|` 分隔单元格、`---` 分隔表头;`:---` 左对齐、`---:` 右对齐、`:---:` 居中
- 代码块:``` 包裹并写语言名,可语法高亮

## 为什么这么写 / 权衡
- 比 HTML/LaTeX 学习成本低、专注内容;但复杂格式需嵌入 HTML 补足
- 删除线 `~~`、任务列表属 GFM( GitHub 风格)扩展,跨平台支持不一致

## 坑与最佳实践
- `#` 必须在行首、与文字间留空格
- 标题层级不要跳级(如 2 直接到 4),保持结构清晰
- 文件后缀用 .md / .markdown
