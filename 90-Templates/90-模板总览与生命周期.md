# 90-Templates 总览 & 一个项目的完整生命周期

> **属于哪层:** `90-Templates\` 模板层——**所有骨架的工厂,格式统一靠它**。
> **作用:** 此层不存"笔记内容",只存"怎么写的骨架"。写新笔记时复制一份去 20-Areas / 10-Projects 等,模板本身永远不改。
> **要点:** 模板是"给格式"的工具;看懂 90 层最好的方式,是看同一个项目如何走完 00→10→20→30→40 全程。

## 一、各层模板一览

| 模板文件(都在本目录) | 给哪层用 | 复制成 | 一句话 |
|----------------------|---------|--------|--------|
| `00-MOC模板.md`  | 00-MOC 索引 | `00-MOC\{专题}.md` | 一专题一张地图,只放链接 |
| `10-项目立项模板.md` | 10-Projects 项目 | `10-Projects\{目标}-{截止}\` | 有目标+截止,一个文件夹一件事 |
| `20-笔记正文模板.md` | 20-Areas 领域(成品) | `20-Areas\{科目}\{笔记名}.md` | 正文唯一存放处,一篇一主题 |
| `算法题.md` / `系统设计.md` / `语言技术.md` / `项目学习.md` | 20-Areas(细分) | 同上 | 各类别的专门骨架 |
| `30-资源暂存模板.md` | 30-Resources 原料 | `30-Resources\tools\{名}.md` | 未消化的原始资料 |
| `40-归档封存模板.md` | 40-Archive 封存 | `40-Archive\{原名}\` | 完结/过时沉底,只进不出 |

## 二、一个项目的完整生命周期(以「学习 Markdown」为例)

> 六个模板 + 示例分散在上方各文件,这里把**同一条线**串起来。**记忆:同一份知识,随它"越学越透",在 30→20→10→00→40 之间流动;90 永远提供格式。**

```
【想学 Markdown / 看到教程】                              模板来自 90-Templates
      │
      ▼
 30-Resources  ← 30-资源暂存模板.md  │ 先囤原料:菜鸟教程页面、语法速查截图(只收藏,不学)
      │ 提炼
      ▼
 20-Areas  ← 20-笔记正文模板.md(及 算法/系统/语言/项目 细分) │ 变成成品:《Markdown语法》,带 frontmatter
      │ 要系统学,立项
      ▼
 10-Projects  ← 10-项目立项模板.md  │ 立《掌握Markdown-2026Q4》:目标+截止+对应教程章节的任务清单,边学边把知识写回 20-Areas
      │ 学出来后,在
      ▼
 00-MOC  ← 00-MOC模板.md  │ 登记进《编程语言 MOC》的"标记语言",让成品"可见可检索"
      │ 学完 / 过时
      ▼
 40-Archive  ← 40-归档封存模板.md  │ 项目整体封存;成品笔记留在 20-Areas 继续当参考
```

**逐层解读(这条线上的「Markdown」长什么样):**

| 阶段 | 此刻 Markdown 在哪 | 里面有什么 |
|------|-------------------|-----------|
| ① 30-Resources | `30-Resources\tools\Markdown资料收集.md` | 3 条未提炼的原始素材(菜鸟教程总览/分章/速查截图) |
| ② 20-Areas | `20-Areas\02-编程语言\Markdown语法.md` | 一篇**成品**笔记:本质 + 标题/列表/表格/代码块语法 + 权衡 + 坑(带 frontmatter) |
| ③ 10-Projects | `10-Projects\掌握Markdown-2026Q4\` | 目标/截止/任务清单(对应菜鸟教程各章);完成后整体移 40 |
| ④ 00-MOC | `00-MOC\编程语言.md` 里一行 `- [Markdown语法](<...>)` | 只加一行链接做入口 |
| ⑤ 40-Archive | `40-Archive\掌握Markdown-2026Q4\` | 封存说明:起止/结论/可复用语法速查 |
| ⑥ 90-Templates | 上面的模板 | 全程提供骨架,写完不改 |

**三条铁律(贯穿全程):**
1. **正文只来自 20-Areas**——00 只指路、10 只立项、30 只暂存、40 只封存,谁也不存正文。
2. **内容往沉淀走**:30→20 是"收藏变知识";10→40 是"项目变档案";90 全程给格式。
3. **一篇笔记可以属于多个层(不同时间)**:同一篇《Markdown语法》在②是 20-Areas 成品,在③被项目引用,在④被 MOC 索引——位置表示它此刻的角色,不是它的分类。

## 三、新增一个模板时的规则
1. 模板存本目录,文件名 = 「层名 + 用途」,内容 = 空骨架 + 一个 `▼ 填充后长这样` 示例。
2. 示例必须来自真实/可设想的项目,和本文件第二节保持同一套例子(目前统一用"学习 Markdown"),方便对照。
3. 所有链接用相对路径 `<相对路径>`,保证 VS Code / Obsidian / GitHub 可点跳。
