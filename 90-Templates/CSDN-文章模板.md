# CSDN 博客文章模板(参考 lvy/lvynote 的文章风格)

> 适用:在 CSDN 上用 Markdown 编辑器写技术博客。模板含 **3 个可选方案**,按"这篇文章是什么类型"来选。
> 风格来源:lvynote.blog.csdn.net(lvy-);特征:标题带 `[分类]` 前缀、结构化 H2/H3 层级、开头给外部链接+一句话简介、代码块+配图、结尾总结。
> **用法:** 每个方案下方是"可直接复制进 CSDN"的完整骨架;源文(含代码块标记)从编辑器源码模式复制即可。

---

**标题格式:** `[分类] docs | 主题`(例:`[rStar] docs | 求解协调器`)

## 通用规范(三种都用)

| 项 | 做法 |
|----|------|
| 标题 | 带 `[分类]` 前缀,`分类` 用英文/拼音短词(如 `rStar/MySQL/AI-video/C++`) |
| 开头 | 1 句简介 + 官方/原文链接(可读性 & 防抄) |
| 正文 | H2/H3 分层;概念+示例成对出现;每节短小 |
| 代码 | Markdown 代码块标语言(CSDN 会高亮) |
| 配图 | 每篇 2~6 张(流程/截图),CSDN 编辑器直接粘贴上传 |
| 结尾 | 总结 + 下一步/下一篇预告(利于连读) |
| 标签/目录 | 配好 tags;长文勾选"生成目录" |
| 发布 | 正文前加一句"本文首发于 CSDN"或统一声明(可选) |
