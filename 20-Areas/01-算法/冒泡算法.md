# 冒泡算法

> 本笔记是 `90-Templates\20-笔记正文模板.md` 骨架的示范样例。

## 题意(用自己的话)

把一个无序数组排成升序。反复扫描数组,比较相邻两个元素,顺序错了就交换;每一轮扫描都会把当前未排序部分里最大的元素"冒泡"到末尾。

## 直觉与试错

- 第一反应:相邻比较、大数后移,是最直观的排序思路
- 踩坑:内层循环边界容易写错——第 i 轮结束后末尾 i 个已有序,内层只需扫到 `n-i-1`,写成 `n-1` 会做无用功(不算错但浪费)
- 卡住的原因:无。适合建立"边界收缩"的直觉,这个直觉在插入/选择排序里通用

## 核心思路

- 关键观察:每轮完整扫描后,最大元素必然沉到未排序区末尾 → 未排序区每轮缩 1
- 算法选择:双重循环 + 相邻交换。优化点:某轮没有发生任何交换 → 已经有序,提前退出(最好情况 O(n))

## 代码

```python
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):            # 共 n-1 轮
        swapped = False
        for j in range(n - 1 - i):    # 边界收缩:末尾 i 个已就位
            if a[j] > a[j + 1]:       # 相邻逆序 → 交换(稳定的关键:用 > 不用 >=)
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:               # 本轮无交换 → 已有序,提前收工
            break
    return a
```

## 复杂度

- 时间:O(n²) 最坏/平均;O(n) 最好(已有序 + swapped 提前退出),因为比较次数为 (n-1)+(n-2)+…+1
- 空间:O(1),原地交换,只用常数个临时变量
