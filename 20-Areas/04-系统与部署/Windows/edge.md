# 快捷键

`Ctrl + T`:打开新标签页

`Ctrl + W`:关闭当前标签页

`Ctrl + L`:光标移动到搜索栏

`Ctrl + F`:查找当前页面内容

`Ctrl + Tab`:切换至下个标签页

`Ctrl + Shift +Tab`:切换至上个标签页

`Ctrl + R`:刷新当前页面

`Ctrl + Shift + T `:重新打开刚才关闭的标签页

`Ctrl + Shift + E`:侧边栏搜索选中行

`Ctrl + Shift + A`:搜索**已打开**标签页和标签页组
