# Markdown 语法全速查(语法 · 作用 · 示例)

> 本笔记由项目 `10-Projects/2026-10-掌握Markdown` 提炼,内容整理自菜鸟教程(runoob.com)。
> **用法**:每个语法给「**语法**(字面写法)→ **作用** → **示例/效果**」。想不起来时来这里查一条,复制即用。

## 一句话本质

用 `#`、`*`、`|` 等直观符号写**纯文本**,由解析器转成 HTML/PDF/Word。易读易写、纯文本可 diff、与版本控制友好。文件后缀 `.md` / `.markdown`。

---

## 1. 标题 Heading

- **语法:** `#`~`######` 表示 1~6 级(`#` 在行首、与文字间留空格);也可用下一行的 `=` 表示一级、`-` 表示二级。
- **作用:** 组织文档层级结构,生成目录、方便跳转。
- **示例/效果:**

  ```markdown
  # 一级标题
  ## 二级标题
  ####### 不会生效(最多6级#)
  ```

  本文件所有大标题就是 `#`/`##` 的演示。守则:行首、留空格、**不跳级**(如 2 直接到 4)。

## 2. 段落与换行

- **语法:** 空行分段;行尾两个空格再回车 = 换行;行尾一个回车 = 空格。
- **作用:** 控制文本的段落与换行节奏。
- **示例/效果:**

  ```markdown
  这是第一段。

  这是第二段(中间有空行=新段落)。
  本行前面没有空行,会接在上一行后面。
  ```


## 3. 强调(粗体 / 斜体 / 删除线 / 下划线)

- **语法:** `*斜体*` / `_斜体_`、`**粗体**` / `__粗体__`、`***粗斜***`、`~~删除线~~`、`<u>下划线</u>`(HTML)。
- **作用:** 给文字加视觉强调,最常用的排版手段。
- **示例/效果:** `**粗体**` → **粗体**;`*斜体*` → *斜体*;`~~删除~~` → ~~删除~~;`<u>下划线</u>` → <u>下划线</u>。

## 4. 列表(有序 / 无序 / 嵌套 / 任务)

- **语法:** 无序 `*`、`+`、`-` + 空格;有序 `1.`、`2.`;嵌套靠缩进 2~4 空格;任务列表 `- [ ]`(未完成)/ `- [x]`(完成)。
- **作用:** 罗列要点、步骤、待办。
- **示例/效果:**

  ```markdown
  - 无序项 A
    - 嵌套项(缩进)
  1. 有序项一
  2. 有序项二
  - [x] 已完成任务
  - [ ] 未完成任务
  ```

  > 注意:GMF 的任务列表并非所有平台支持,跨平台先确认。

## 5. 链接

- **语法:** 行内 `[文字](网址)`、带标题 `[文字](网址 "悬停提示")`、引用式 `[文字][id]` + 文末 `[id]: 网址`、自动链接 `<https://x.com>`。
- **作用:** 跳转外链、站内互相引用。
- **示例/效果:** `[菜鸟教程](https://www.runoob.com)` → [菜鸟教程](https://www.runoob.com);`<https://www.runoob.com>` → <https://www.runoob.com>。

## 6. 图片

- **语法:** `![替代文字](图片地址 "标题")`;想带链接就整张图包进 `[...](链接)`。
- **作用:** 插入截图/流程图(CSDN/Obsidian 可直接粘贴路径或拖入)。
- **示例/效果:** `![示例图](https://www.runoob.com/wp-content/uploads/2019/03/iconfinder_markdown_298823.png)` ↓

![示例图](https://www.runoob.com/wp-content/uploads/2019/03/iconfinder_markdown_298823.png)

## 7. 引用 Blockquote

- **语法:** 行首 `>`;`>>` 嵌套;引用里可放列表/代码。
- **作用:** 引用原文、标注提示、给"引言"。
- **示例/效果:**

  ```markdown
  > 我是引用。
  > 
  > > 我是嵌套引用。
  ```

  效果即本文件各处"`>`"开头的灰色引言块。

## 8. 代码(行内 / 围栏代码块)

- **语法:** 行内代码用单个反引号包裹 `` `code` ``;多行代码块用 **3 个反引号**包裹并写明语言名开启高亮(如 ```` ```python ````)。
- **作用:** 展示代码/命令,高亮可读。
- **示例(行内):** `` `print("hi")` `` → `print("hi")`
- **示例(围栏,写的时候这样填):**


  ```markdown
  这是围栏代码块的写法(复制时把下面的缩进去掉):

      ```python
      print("hello")
      ```
  ```


  渲染后即本文件里那些带语言的代码块(如本节上方)。语言名不写也可以,只是不高亮。

## 9. 表格

- **语法:** 表头行 + `---` 分隔行 + 数据行;`:---` 左对齐、`---:` 右对齐、`:---:` 居中。
- **作用:** 结构化对比数据。
- **示例/效果:**

  ```markdown
  | 左对齐 | 居中 | 右对齐 |
  |:------|:----:|-------:|
  | a     |  b   |      c |
  ```

  渲染后:

  | 左对齐 | 居中 | 右对齐 |
  |:------|:----:|-------:|
  | a     |  b   |      c |

## 10. 分割线

- **语法:** 单独一行 `---`、`***` 或 `___`。
- **作用:** 内容分隔。
- **示例/效果:** 本文件每两大节之间的横线就是 `---`。

## 11. HTML 嵌入

- **语法:** 直接写 `<div>`、`<span>`、`<u>`、`<center>` 等 HTML 标签。
- **作用:** Markdown 不够用时补复杂格式(居中/颜色/布局)。
- **示例/效果:** `<center>居中文字</center>` → <center>居中文字</center>;`<u>带下划线</u>` → <u>带下划线</u>。

## 12. 转义

- **语法:** 反斜杠 `\` 加在特殊字符前:`\*`、`\#`、\` 等。
- **作用:** 想显示字面符号(而不是触发语法)时用。
- **示例/效果:** `\*不是斜体\*` → \*不是斜体\*。

## 13. GFM 扩展(GitHub 风格,非原生标准)

- **语法:** 任务列表(`- [x]`)、删除线(`~~`)、自动链接、表格、脚注(`[^1]` + 文末 `[^1]: 内容`)。
- **作用:** GitHub/CSDN 等平台额外支持,写 README 常用。
- **示例/效果:** 脚注示例:这是脚注引用[^1]。
  [^1]: 这是脚注内容(本文档末尾会显示)。

## 14. 数学公式(KaTeX/LaTeX,平台支持时)

- **语法:** 行内 `$公式$`;块级 `$$ 公式 $$`。
- **作用:** 数学/算法笔记写公式。
- **示例/效果:** `$E=mc^2$` → $E=mc^2$(不支持时显示为纯文本)。

## 15. 目录与锚点

- **语法:** GitHub 自动给标题生成锚点;可用 `[跳转](#标题锚点)` 手动跳。
- **作用:** 长文档导航。
- **示例/效果:** [回到第1节标题](#1-标题-heading)。可滚动验证跳转。

## 常见坑(用了立省)

- `#` 不在行首/不留空格 → 不解析为标题。
- 表格分隔线少于 3 个 `-` → 不渲染成表格。
- 行尾只敲一个回车 → 变空格不换行;要换行需两空格+回车。
- 删除线/任务列表/脚注是 GFM 扩展,跨平台(如简书)可能不显示。
- 数学公式/nav/Latex 依赖具体编辑器是否开启。
