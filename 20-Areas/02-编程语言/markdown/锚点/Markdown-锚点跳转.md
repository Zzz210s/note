# Markdown 锚点跳转(设跳转点 + 别处引用)

> 需求:**在一个文件里设一个"点",在别处写一行链接,点击直接跳到那个点。**
> 两种做法,按需选用:
> ① **标题自动锚点**——零成本,靠标题自动生成(英文/数字标题最好用);
> ② **HTML 显式锚点**——可在任意位置设点,中文最稳,跨平台兼容性最好。

---

## 一、标题自动锚点(最简单)

**作用:** 让"某个标题"成为跳转点;跳转链接 = `[文字](#标题锚点)`(本文件内)或 `[文字](其他文件.md#标题锚点)`(跨文件)。

**规则(GitHub/VS Code):** 标题自动生成锚点 id = 标题**转小写、空格变 `-`、去掉标点符号**。
例:`## How to Jump` → 锚点 `#how-to-jump`。

**写法(字面):**
- 本文件内:`[跳到 How to Jump](#how-to-jump)`
- 跨文件:`[跳到语法速查·锚点一节](../Markdown语法.md#15-目录与锚点)`

**实测(点下面的链接真的会跳,可验证):**
- 本文件内 → [跳到「How to Jump」](#how-to-jump)(跳到下方标题)
- 跨文件 → [跳到 Markdown语法.md 的「15. 目录与锚点」](../Markdown语法.md#15-目录与锚点)
- 跨文件 → [跳到 Markdown语法.md 的「1. 标题 Heading」](../Markdown语法.md#1-标题-heading)

## How to Jump

这是一个**英文标题**,自动锚点是 `#how-to-jump`。上面第一条链接就是跳到这里的。

## 二、HTML 显式锚点(任意位置 · 中文最稳 · 推荐)

**作用:** 把 `<a id="名字"></a>` 插在**任何位置**(不一定是标题),这一处就成为跳转点;链接写法同上,id 直接用。
**为什么推荐:** 中文标题自动锚点很难猜(标点被删、是否转小写各平台不一),显式锚点 id 完全自己定,稳定可控。

**写法(字面):**
```markdown
<a id="中文跳转点"></a>          <!-- 放在想跳到的位置 -->
[跳到中文跳转点](#中文跳转点)      <!-- 本文件内引用 -->
[跳到中文跳转点](其他文件.md#中文跳转点) <!-- 跨文件引用 -->
```

> **lint 警告:** 若启用 VS Code markdownlint,`<a id>` 属内联 HTML,默认规则 **MD033** 会报错;请改用「标题自动锚点」写法或见 [Markdown-锚点与markdownlint.md](<Markdown-锚点与markdownlint.md>)。

**实测(本文件内):**
- ↓ 下方第 1 行就放着一个 `<a id="中文跳转点">` 空锚点,点这条能跳过去 →
  [跳到中文跳转点](#中文跳转点)

<a id="中文跳转点"></a>
**你到了。** 这一行前面的 `id="中文跳转点"` 就是被跳到的"点"。显式锚点不依赖标题,放在段首、标题旁、表格前都行。

## 三、跨文件跳转完整示意

假设你要从「A.md」跳到「B.md」里某个位置:

```markdown
<!-- B.md 中:在目标位置放显式锚点 -->
<a id="目标段"></a>

<!-- A.md 中:引用它,同一目录直接写文件名 -->
[跳转到 B 的目标段](B.md#目标段)
```

要点:
- 路径跟普通文件链接一样:**同目录写文件名**,子目录写 `文件夹/文件.md`,上级写 `../`。
- 锚点部分就是 `#名字`,紧跟文件路径之后;**`#` 号不能丢**。
- 本仓库约定用相对路径,带空格或特殊字符的路径可用 `<>` 包裹整条链接(如 `[文字](<目录/文件#锚点>)`)。

## 四、平台差异与坑

| 平台 | 标题自动锚点 | HTML 显式锚点 |
|------|-------------|--------------|
| GitHub / VS Code / Obsidian | 支持 | 支持 |
| CSDN 编辑器 | 部分支持(标题锚点不稳) | 相对更稳 |
| 简书 / 微信公众号 | 基本不支持 | 不支持 |

坑清单:
- **重复标题**会自动加后缀 `-1`、`-2` 等:`## 总结`、`## 总结` → `#总结`、`#总结-1`。
- 锚点**大小写敏感**(`#How-to-jump` ≠ `#how-to-jump`)。
- 中文标题自动锚点:**标点(、。：)会被删掉**,空格变 `-`,很难手写——中文场景直接用 HTML 锚点最省心。
- 引用时 `#` 必须紧跟在路径后,别留空格:`(file.md#锚点)` 对,`(file.md #锚点)` 错。
- 在 Obsidian 里也认 `#锚点` 跳转;在 CSDN 发稿时,建议把关键跳转点都换成 HTML 锚点。
