在 Ubuntu 24.04 上使用 Docker 部署 Nginx 和 MySQL 来搭建网站，最优雅、最高效的方式是使用 **Docker Compose**。这种容器化的部署方式能让你的 VPS 环境保持绝对的整洁，非常适合后续扩展和管理各种自托管服务或开发环境。

下面为你整理了一份详细的实操指南。

---

## 第一步：连接 VPS 并更新系统

首先，通过 SSH 登录你的 VPS，运行以下命令确保系统软件包是最新的：

```bash
sudo apt update && sudo apt upgrade -y

```

---

## 第二步：安装 Docker 和 Docker Compose

在 Ubuntu 24.04 上，推荐使用 Docker 官方的安装脚本，它会自动配置好最新的稳定版软件源并完成安装（包含 Docker Engine 和 Compose 插件）。

1. **下载并运行官方安装脚本：**
```bash
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

```


2. **启动并设置 Docker 开机自启：**
```bash
sudo systemctl enable --now docker

```


3. **验证安装是否成功：**
```bash
docker --version
docker compose version

```


*如果能正常输出版本号，说明基础容器环境已经就绪。*

---

## 第三步：规划项目目录结构

为了方便后期维护，建议把所有的配置文件、数据库数据和网站源码收拢在同一个目录下。在当前用户的家目录下创建一个 `website-stack` 文件夹：

```bash
mkdir -p ~/website-stack/{html,nginx,mysql-data}
cd ~/website-stack

```

此时的目录规划如下：

* `~/website-stack/`：主工作目录
* `~/website-stack/html/`：存放网站静态文件（如 `index.html` 或前端打包文件）
* `~/website-stack/nginx/`：存放 Nginx 的自定义配置文件
* `~/website-stack/mysql-data/`：存放 MySQL 数据（实现数据持久化）

---

## 第四步：编写 Docker 编排配置文件

在 `~/website-stack` 目录下，创建一个名为 `docker-compose.yml` 的文件：

```bash
nano docker-compose.yml

```

将以下内容复制进去（**务必修改 MySQL 的强密码**）：

```yaml
services:
  # 数据库服务
  mysql:
    image: mysql:8.0
    container_name: mysql_db
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: your_secure_root_password  # 替换为复杂的 root 密码
      MYSQL_DATABASE: my_website_db                  # 自动创建的数据库名称
      MYSQL_USER: web_user                            # 自动创建的普通用户名
      MYSQL_PASSWORD: web_secure_password            # 普通用户密码
    volumes:
      - ./mysql-data:/var/lib/mysql                  # 挂载本地目录以持久化数据
    networks:
      - web_net

  # Web 服务器服务
  nginx:
    image: nginx:alpine
    container_name: nginx_web
    restart: always
    ports:
      - "80:80"                                      # 映射 HTTP 端口
      # - "443:443"                                  # 预留给后续配置 SSL 证书
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro  # 挂载 Nginx 主配置文件
      - ./html:/usr/share/nginx/html:ro              # 挂载网站根目录
    depends_on:
      - mysql                                        # 确保 MySQL 在 Nginx 之前启动
    networks:
      - web_net

# 定义内部网络
networks:
  web_net:
    driver: bridge

```

保存并退出（在 `nano` 中按 `Ctrl + O` 保存，`Enter` 确认，`Ctrl + X` 退出）。

---

## 第五步：编写 Nginx 配置与前端测试页面

### 1. 配置 Nginx

在 `~/website-stack/nginx/` 目录下创建 `nginx.conf` 文件：

```bash
nano nginx/nginx.conf

```

填入以下基础的 Web 服务器配置。这个配置足以作为静态文件服务，或者未来修改为反向代理你的后端服务（如 Java、C++ 或其他 Web3 应用接口）：

```nginx
events {
    worker_connections 1024;
}

http {
    include       /etc/nginx/mime.types;
    default_type  application/octet-stream;

    server {
        listen 80;
        server_name localhost; # 后续绑定域名后，将此处修改为你的域名

        location / {
            root   /usr/share/nginx/html;
            index  index.html index.htm;
        }

        error_page   500 502 503 504  /50x.html;
        location = /50x.html {
            root   /usr/share/nginx/html;
        }
    }
}

```

### 2. 创建测试网页

在 `~/website-stack/html/` 目录下创建一个简单的 `index.html`：

```bash
nano html/index.html

```

写入测试代码：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>网站运行状态</title>
    <style>
        body { font-family: system-ui, sans-serif; text-align: center; margin-top: 100px; background-color: #1e1e2e; color: #cdd6f4; }
        h1 { color: #89b4fa; }
    </style>
</head>
<body>
    <h1>系统已上线</h1>
    <p>Nginx 容器正在运行，MySQL 数据库已在后台就绪。</p>
</body>
</html>

```

## 第六步：一键启动并验证

一切准备就绪，回到主目录，执行启动命令：

```bash
cd ~/website-stack
sudo docker compose up -d

```

Docker 会自动拉取 Nginx 和 MySQL 的镜像并启动容器。`-d` 参数表示在后台运行。

### 检查运行状态：

```bash
sudo docker compose ps

```

如果看到 `mysql_db` 和 `nginx_web` 的状态都是 `Up`，说明容器已全部正常启动。

### 访问测试：

打开浏览器，在地址栏输入你 **VPS 的公网 IP 地址**。你将会看到刚才写好的测试网页。

## 后续运维常用命令集

在 `~/website-stack` 目录下，你可以使用以下命令来管理你的技术栈：

* **查看实时日志**（排查网络或启动问题）：
```bash
sudo docker compose logs -f

```


* **重启 Nginx 服务**（当你修改了 `nginx.conf` 之后）：
```bash
sudo docker compose restart nginx

```


* **进入 MySQL 容器执行 SQL**：
```bash
sudo docker exec -it mysql_db mysql -u root -p

```


* **关闭并移除容器**（数据因为挂载了本地目录，**不会**丢失）：
```bash
sudo docker compose down

```
