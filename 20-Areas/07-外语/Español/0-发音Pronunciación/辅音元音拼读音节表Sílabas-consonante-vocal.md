# 辅音元音拼读音节表(Sílabas consonante + vocal)

> 2026-09-02 学习沉淀(记录见 [2026-09-02 每日记录](<../../../10-Projects/2026-掌握西班牙语B2/08-每日笔记/2026-09-02.md>))。
> 相当于西语的"罗马音表":每个辅音拼 a/e/i/o/u 五个元音。与 [单字母发音](<./单字母发音Pronunciación de una sola letra.md>) 配套:那篇讲单字母,本篇讲拼读组合。

## 一、完整拼读表

> 清 = sorda(声带不振动),浊 = sonora(声带振动)。斜体行(l/ll/r/s/f)为补全行。

| 辅音 | 拼读组合 | 音质与要点 |
| --- | --- | --- |
| n | na ne ni no nu | |
| m | ma me mi mo mu | |
| ñ | ña ñe ñi ño ñu | 腭化鼻音,类似"捏"的声母 |
| l | *la le li lo lu* | 补全 |
| ll / y | *lla lle llo llu / ya ye yi yo yu* | 补全;ll 与 y 同音(耶音) |
| r / rr | *ra re ri ro ru* | 补全;词首/词中 rr 为齿龈颤音 |
| s | *sa se si so su* | 补全 |
| p | pa pe pi po pu | 清 [p] |
| b / v | ba be bi bo bu / va ve vi vo vu | **浊;b 与 v 完全同音**(西语 v 读 b 音) |
| t | ta te ti to tu | 清 [t] |
| d | da de di do du | 浊 [d] |
| c / qu | ca que qui co cu | 清 [k];**c 后接 e/i 时改发 [θ]/[s]**,拼法相应变为 ce ci |
| z | za zo zu | 清;与 ce ci 合并:za-ce-ci-zo-zu 五种拼法同一个音(西班牙 [θ],拉美 [s]) |
| k | ka ke ki ko ku | 清 [k],仅用于外来词 |
| g | ga go gu;gue gui | 浊 [g];gue/gui 中 **u 不发音**(仍 [g]);要读出 u 音须加曲音符:güe güi |
| j(及 g+e/i) | ja je ji jo ju;ge gi | 清 [x](喉擦音);ge gi 与 je ji 同音 |
| ch | cha che chi cho chu | 清,类似"恰"声母 |
| f | fa fe fi fo fu | 清 |

## 二、三条核心拼读规则

1. **b = v**:两者拼写不同、读音完全相同(浊双唇音),这是西语听写最大坑点。
2. **一个音多套拼法**:/θ/ 有 za-ce-ci-zo-zu 五种写法;/k/ 有 ca-que-qui-co-cu(及 ka)五种;/x/ 有 ja-je-ji-jo-ju 与 ge-gi 两种——**发音不决定拼写,拼写决定发音**,记词必须连拼写一起记。
3. **u 的两种"隐身"**:gue/gui 里 u 静默(保 [g] 音);加曲音符 ü 才发声(güe güi = [gwe] [gwi])。
