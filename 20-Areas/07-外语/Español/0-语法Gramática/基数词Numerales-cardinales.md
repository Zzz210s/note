# 基数词(Los numerales cardinales)

> 2026-09-02 学习沉淀(记录见 [2026-09-02 每日记录](<../../../10-Projects/2026-掌握西班牙语B2/08-每日笔记/2026-09-02.md>))。
> 一类词:表数量的基数词。掌握两层:**分段词形**(哪些连写、哪些加 y、哪些不规则)+ **形容词用法**(配合与缩约)。

## 一、分段词形表

| 段位 | 词形 | 规则要点 |
| --- | --- | --- |
| 0-10 | cero, uno, dos, tres, cuatro, cinco, seis, siete, ocho, nueve, diez | 基础词根 |
| 11-15 | once, doce, trece, catorce, quince | 独立词形,无规律,硬记 |
| 16-19 | dieciséis, diecisiete, dieciocho, diecinueve | dieci + 个位,**连写一个词**(dieciséis 带重音符号) |
| 20-29 | veinte, veintiuno, veintidós, veintitrés, ..., veintinueve | veinti + 个位,**连写一个词**(veintidós/veintitrés/veintiséis 带重音) |
| 30-90 十位词 | treinta, cuarenta, **cincuenta**, sesenta, setenta, ochenta, noventa | 注意 cincuenta(易误作 cincuento) |
| 31-99 | treinta y uno, ..., noventa y nueve | 十位与个位(非 0)之间用 **y** 连接;20-29 已连写融合,不再加 y |
| 100 | cien | 恰好 100,或作形容词置于名词前(此时 ciento 缩为 cien):cien años |
| 101-199 | ciento uno, ciento dos, ..., ciento noventa y nueve | ciento + 余数 |
| 200-900 | doscientos/-as, trescientos/-as, cuatrocientos/-as, **quinientos/-as**, seiscientos/-as, **setecientos/-as**, **ochocientos/-as**, **novecientos/-as** | 词尾 -cientos;粗体四个词干不规则(quin-/set-/och-/novec-,来自拉丁语) |
| 1000 | mil | **1000-1999 用 mil 不用 un mil**:mil novecientos noventa y nueve = 1999;mil uno = 1001;mil 无性数变化 |
| 100 万+ | un millón, dos millones, cinco millones | millón 是**阳性名词**(非形容词),复数 millones;**后接名词须加 de**:cinco millones de kilómetros |

## 二、形容词用法四规则

1. **前置语序**:数词作形容词置于名词之前,是西语基数词的基本语序。
2. **性一致**:200-900 与名词性一致,阴性用 -as 形:doscientas rosas / novecientas rosas。
3. **uno 缩约**:uno 及以 -uno 结尾的数词置于阳性名词前省略 o:un libro / veintiún libros。
4. **cien 去尾**:cien 置于任何名词前都去掉 -to:cien años(单独使用或 101-199 仍作 ciento)。

## 三、书写与实例

- 千位分隔用句点:5.000.000 = cinco millones。
- 大数从大到小逐段读:8.145.519 = ocho millones ciento cuarenta y cinco mil quinientos diecinueve habitantes。
- mil 与 millón 的本质差异:mil 是数词(无变化、直接接名词:mil libros);millón 是名词(复数变化、必须加 de:millones de libros)。
