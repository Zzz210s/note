# 程度与数量修饰词(Adverbios de grado y cantidad)

> 2026-09-01 学习沉淀(原始记录见 [2026-09-01 每日记录](<../../../10-Projects/2026-掌握西班牙语B2/08-每日笔记/2026-09-01.md>))。
> 这不是 13 个孤立词条,而是**一类词**:表程度/量级的副词及其可兼作形容词/代词的同族词,回答"到什么程度 / 有多少"。掌握三层:强度谱系(谁强谁弱)-> 语法行为(变不变性数)-> 感情色彩(中性/消极)。

## 一、强度谱系(语义轴)

程度义从"零"到"满格"排一条轴:

```text
 0%      低          中           高        超标        100%
nada    apenas  poco  un poco  algo  medio  bastante  muy / tan  demasiado  completamente
(零)   (几乎不) (不足) (一点) (稍微) (半/有点) (相当)  (很/那么)  (过头)     (完全)
```

两个**编外词**(不落在强度轴上):

- **casi**——"接近但未到",给动词/数量/形容词加"差一点"限定:Casi caigo.(差点摔倒)/ Tengo casi cien euros.(快一百欧)
- **mucho**——"大量/高频",主要修饰动词与名词,**表量不表度**:Llueve mucho. / Tengo mucho trabajo.

感情色彩分野(易错核心):

- 消极/否定:**nada**(归零)、**poco**(不足)、**demasiado**(过量)
- 中性:un poco、algo、medio、bastante、muy、tan、mucho、completamente
- 因此"想要一点"说 un poco,"嫌少"才是 poco;"很贵"是 muy caro,"贵得离谱(劝退)"是 demasiado caro。

## 二、语法行为三组(怎么变形)

| 组 | 词 | 行为 |
| --- | --- | --- |
| **A 纯副词** | muy / tan / casi / apenas / completamente / totalmente | 永不变形;只修饰形容词、副词、动词;**从不直接修饰名词** |
| **B 副/形双身份** | mucho / demasiado / poco | 修饰形/副/动时不变(副词用法);修饰名词时性数配合(形容词用法):mucho → mucha/muchos/muchas 等 |
| **C 边缘不规则** | bastante / medio / nada / algo | 见下四条 |

- **bastante**:形容词只变单复数,阴阳性同形(bastante dinero / bastantes personas)
- **medio**:副词不变;形容词表"半个",**阴单用 media**(media hora / media manzana),阳性与复数用 medio
- **nada**:副词须与 no 连用,**no...nada 双重否定 = 否定**(No estoy nada cansado);另有代词身份(No hay nada)
- **algo**:副词不变;另有代词身份(Quiero comer algo)

一句话:能不能修名词,看 B/C 组;一旦站到名词前,就要配合。

## 三、易混对比(B2 高频考点)

1. **poco vs un poco**:poco = 不足(贬),un poco = 一点(中性)。Tengo poca paciencia.(我没什么耐心)/ Dame un poco de paciencia.(给我一点耐心)
2. **muy vs mucho**:muy + 形/副;mucho + 动词(干得多)或名词(多)。`muy mucho` 是错的
3. **tan vs tanto**(拓展):tan + 形/副(那么快 tan rápido);tanto/tanta/tantos/tantas + 名词(那么多);`tan...como` = as...as 同级比较
4. **bastante 双义**:副词"相当"(程度中上)与形容词"足够"(数量够用)同形,靠语境分辨:Tengo bastante dinero 可解作"钱相当多"或"钱够了"
5. **demasiado vs muy**:muy 中性高强度;demasiado 越过合理线,自带负面评价
6. **nada 双重否定**:西语否定词叠加仍是否定,与英语 not...anything 对应:No vi nada = I didn't see anything

## 四、速查表(按谱系重排)

| 谱系位 | 词 | 对应英文 | 词形变化 | 用法要点 |
| --- | --- | --- | --- | --- |
| 0(零) | nada | not at all / nothing | 不变 | 副词:一点也不(与 no 连用);代词:什么也没有 |
| 低 | apenas | barely / hardly | 不变 | 副词:几乎不;仅仅/刚刚 |
| 低(不足) | poco | little / few | 有性数变化 | 副词:不太;形容词:少的(消极) |
| 低中(一点) | un poco | a little / a bit | 不变 | 一点(中性);un poco de + 名词 |
| 低中(稍微) | algo | somewhat / something | 不变 | 副词:稍微;代词:某事某物 |
| 中 | medio | half / sort of | 副词不变;形容词 media(阴单) | 副词:有点;形容词:半个 |
| 中高 | bastante | quite / enough | 仅单复数变化 | 副词:相当;形容词:挺多的/足够 |
| 高 | muy | very | 不变 | 副词:非常 |
| 高 | tan | so | 不变 | 副词:如此,那么 |
| 超标 | demasiado | too / too much | 有性数变化 | 副词:太,过分;形容词:太多的 |
| 100% | completamente / totalmente | completely / totally | 不变 | 副词:完全地,彻底地 |
| 编外 | casi | almost / nearly | 不变 | 接近但未到:差点/几乎 |
| 编外 | mucho | much / many / a lot | 有性数变化 | 副词(固定 mucho):大量;形容词:许多 |

## 五、例句库

- **nada**:No estoy nada cansado.(一点也不累)/ No hay nada aquí.(这里什么都没有)
- **apenas**:Apenas come.(几乎不吃)/ Tiene apenas diez años.(才十岁)
- **poco**:Es poco común.(不常见)/ Tengo poca agua. / pocos libros.(水少/书少)
- **un poco**:Estoy un poco cansada.(有点累)/ Quiero dormir un poco.(想睡会儿)/ un poco de agua(一点水)
- **algo**:La casa es algo grande.(房子有点大)/ Quiero comer algo.(想吃点东西)
- **medio**:Ella está medio loca.(她有点疯,副词不变)/ Como media manzana.(吃半个苹果)
- **casi**:Casi caigo.(差点摔倒)/ Tengo casi cien euros.(快一百欧)
- **bastante**:Es bastante caro.(相当贵)/ Hay bastantes personas.(人不少)
- **tan**:Es tan rápido.(那么快)/ tan rápido como...(和...一样快)
- **muy**:Él es muy alto. / Habla muy bien.(很高/说得好)
- **mucho**:Te quiero mucho.(很爱你,副词不变)/ Hay muchas flores.(很多花)
- **demasiado**:Es demasiado caro.(太贵了)/ Hay demasiada gente.(人太多)
- **completamente / totalmente**:Estoy completamente seguro.(完全确定)/ Cambió totalmente.(彻底变了)
