## 三、过程中修掉的真问题(值得记下来)

1. **`--t3` 辅助色对比度不足**:浅 `#8b949e`(白底 3.08)/ 暗 `#64748b`(3.75)→ 改 `#69707d` / `#8494a7`(4.98 / 5.76)
2. **令牌重构误删两组规则**:四个外壳尺寸 token + `body.work{height:100vh}` → 状态栏塌成 20px、body 滚动高 18512px
   (活动栏被拉到 18477px 高、整页可滚);已恢复并给 `measure_site` 加「外壳固定高度」断言防回归
3. **项目定位全空**:`intro()` 里 `VAULT_ROOT / section / name` **少了 `10-项目/` 前缀** → 20 张卡都写「暂无定位说明」;
   修路径 + 改成三级来源(`> 定位:` 行 → `MISSION.md` 首个散文段 → `- **目标:**` 行),现在 20 张里 18 张有真实定位
4. **`var()` 别名写错位置**:`--bg-elv:var(--w-raised)` 写在 `:root` 会失效(var() 在**声明处**解析,那里没有 `--w-raised`)
   → 无效值继承下去、chip 底色变透明;别名必须写在 `body.work`
5. **搜索延迟瓶颈不在索引大小**:62 万字符索引下 59.8ms 的瓶颈是逐字符 `normalize('NFKC')` → 改整体折叠后 10.4ms
