## 三、根因(证据链完整)

**机制**(读源码得出):候选窗是一个 **WebView2 窗口**,创建时**故意用 DWM cloaked 隐藏**做预热,只有 **WebView2 首次导航完成后**才揭开。

**决定性日志**(本机 `C:\ProgramData\metasequoiaime` 下的日志,2026-10-03 18:36:07):

```text
ERROR | metasequoiaime::server::webview::edge |
  Edge WebView 初始化失败: edge WebView 启动超时
  (程序: C:\Program Files (x86)\Microsoft\EdgeWebView\Application\153.0.4234.48\msedgewebview2.exe)
```

**而同一份日志里引擎是正常的**:

```text
INFO | 键盘被按下了 ... | 拼音: 'shu' | 候选: 'shu' => 书, 数, 树, ...
```

**所以链条是**:引擎算出候选词(正常)→ **WebView2 初始化超时**(失败)→ **cloak 永远没被揭开** → **用户看不到选字框**。

**超时的原因**:错误里的路径是**版本特定的 `153.0.4234.48`**,而清理时实测**注册表和磁盘都已经是 `154.0.4258.53`** → **WebView2 自动更新时,版本特定路径失效**。因此这是**间歇性**故障(实测现在又正常:`msedgewebview2.exe` 挂在 `MetasequoiaImeServer` 下)。

## 八、复现方法(供 PR 说明用)

在本机可以稳定复现「WebView2 路径失效导致 cloaked」:

1. 记下当前 WebView2 版本目录,例如 `C:\Program Files (x86)\Microsoft\EdgeWebView\Application\<ver>`
2. 把该目录**改名**(或删掉 `msedgewebview2.exe`),模拟"注册表指向的运行时不存在"
3. 重启 `MetasequoiaImeServer`,中文输入 → **选字框不出现**,日志出现 `edge WebView 启动超时`
4. 恢复目录名 → 恢复正常

(若第 2 步的改名被占用阻止,可先结束 `msedgewebview2.exe` 进程再试。)
