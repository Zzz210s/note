# 记录:那条「白嫖 25T 网盘」的评论到底是什么活动

> **重要更新(2026-10 补记):本文第三至十节描述的「E5 拿 5T/25T」路径,已被微软在 2026 年封死。**
> 2026 年 2 月起官方条款把开发者订阅改为:**租户共用存储 300GB 上限、单个用户 OneDrive 上限 10GB**;
> 2026-07 短暂强制后又回退,**2026-09 起重新强制执行**(社区大量实测:5T 变 10GB,后台仍显示 5TB 但实际只有 10GB)。
> **所以:即使花钱拿到 VS Professional 订阅、开了 E5 沙盒,也只有 10GB。** 详见第十二节。

> 起因:2026-10-02 一张微信截图(`微信图片_20261002132637_278_144.jpg`),一条评论说「我曾经也认为 OneDrive 是垃圾软件,直到我白嫖到了 25T 大网盘后,我觉得 OneDrive 是最好的网盘软件」。
> 结论先行:**那是「Microsoft 365 开发者计划」的 E5 开发者订阅(沙盒)**;到 2026 年,**它已经不对普通人免费开放了 —— 需要 Visual Studio Professional/Enterprise 订阅**才有资格。

截图是一篇标题为「**计算机玄学**」的帖子(副标题「你会发现人工智障无处不在」)的**评论区**,共 28 条评论:

所以真正要问的「活动」= **怎么免费拿到 25TB 的 OneDrive**。

## 二、那个活动是什么:Microsoft 365 开发者计划 → E5 开发者订阅

| 项 | 内容 |
|---|---|
| 官方名称 | Microsoft 365 Developer Program(微软 365 开发人员计划) |
| 送什么 | **Microsoft 365 E5 开发者订阅(沙盒)**,含 **25 个用户许可**,独立于生产环境的一整个租户 |
| 期限 | **最长 90 天**,有真实开发活动则**自动续订** |
| 用途限制 | **仅限开发目的** —— 官方原文:若用于开发以外的目的,**可被撤销** |
| 存储 | 租户内 OneDrive 每个用户默认 **5TB**;满足条件后可升到 **25TB** |

**「25TB」是怎么来的**(这是那条评论的关键):

> 25 TB 的路径仍然存在,条件是租户持有包含 **OneDrive Plan 2 / SharePoint Plan 2** 的合格订阅(例如 Office 365 E3/E5),**许可数 ≥ 5**,且有用户**已用满其 5TB 的 90%** —— 满足后系统会自动把该用户的空间提到 25TB。

也就是说:**5TB 用满 90% → 自动升 25TB**(社区实例:有人把监控录像持续同步进 OneDrive,用到 98% 后某天发现空间被自动升到 25TB)。

## 三、2026 年还能参加吗:**门槛已收紧**

| 资格路径 | 现状 |
|---|---|
| **Visual Studio Professional / Enterprise 订阅者** | **可以**(且只要 VS 订阅有效就自动续订,不受"90 天不活跃"影响) |
| ISV Success Program / MAICPP 合作伙伴 | 可以 |
| **普通个人免费申请** | **不行了** —— 现在要求先**加入计划**(需通过上面某条资格路径),之后才能申请 E5 沙盒 |

官方原文:**「在请求开发人员订阅之前,必须先直接或通过 Visual Studio Professional 或企业(如果你是订阅者)加入 Microsoft 365 开发人员计划」**。

→ 所以那条评论描述的「白嫖」,**是 2023 年前后的窗口期**;现在想复制,**得先有一份付费的 VS 订阅**(Pro/Enterprise,不是 Community)。

## 四、风险(官方明说)

- **仅限开发用途**;拿来当私人网盘属于「开发以外的目的」→ **订阅可被撤销**,数据随之失效
- 90 天一轮,靠"活跃度"续期 → 长期当仓库用,随时可能丢
- 教育版同理:资格会被**随时重新验证**

## 五、类似的「大容量免费存储」活动现状

| 方案 | 现状(2026) |
|---|---|
| **Office 365 A1(教育版)** | 师生凭学校邮箱仍可**免费**获得,但 **OneDrive 上限已从"1TB/5TB"降到 100GB**(2024-02-01 起生效) |
| 教育租户整体存储 | 学校租户共 **100TB 池**(按学校计,不是按人给) |
| **Power Apps 开发者计划** | 仍可免费申请,送开发环境与部分 E5 许可(适合做开发,不解决大容量存储) |
| **Microsoft Entra ID Free** | 免费开发租户,**不含**大容量存储 |
| 其它网盘(阿里云盘 / 123 云盘 / Terabox 等) | 各自的免费额度与活动,与微软无关;容量大但同样有"随时改规则"的风险 |

## 六、一句话总结

**那条评论说的活动 = 微软 E5 开发者订阅(沙盒),靠"5TB 用到 90% 自动升 25TB"拿到 25T。**
**2026 年已经不能纯免费申请了 —— 需要 Visual Studio Professional/Enterprise 订阅;而且官方明确写着只能用于开发,挪作私人网盘可被撤销。**
教育版 A1 还在,但 OneDrive 已被砍到 100GB,不再是"大容量白嫖"的路径。

## 十、闲鱼上卖的「5T 扩容」是怎么做的(2026-10 调研)

### 先说明:闲鱼站点抓不到实时商品

闲鱼(goofish.com)是纯前端渲染 + 需登录,页面只返回 11KB 的空壳 HTML,商品列表走 XHR 且要登录态 —— **无法直接抓取**。以下结论来自**卖家自己的商品页**与**社区讨论**(V2EX / 主机论坛),属于对"这类交易"的共性分析,不是某一条具体商品。

### 卖的是什么

主流是**子账号**(子号),不是独立账号:

| 类型 | 典型价格 | 说明 |
|---|---|---|
| 5T OneDrive for Business 子号 | 约 **35 元/年**(闲鱼);第三方小店 49 元起 | 卖家自己租户里的一个用户 |
| A1 / A1 Plus 教育版子号 | 数十元 | 声称"理论永久";A1P 可激活桌面 Office |
| E3 MSDN 子号 | 更贵 | 来源是 MSDN 订阅,已停止新发,存量仍能用 |
| E5 开发者子号 | 便宜 | 25 个许可的沙盒,90 天一轮靠活跃度续 |

### 他们的实现方法(技术路径完全公开)

**第一步:先弄到一个「全局租户」** —— 这是唯一真正的门槛

- **E5 开发者订阅**(官方活动,25 许可)
- **A1 / A1 Plus 教育版**(学校域名开出来的全局)
- **E3 MSDN**(MSDN 订阅附带的福利,已停止新发)
- 少数是"薅来的"或历史遗留的全局

**第二步:把子号配额从默认 1T 改成 5T** —— 有两条路,都用官方 PowerShell:

```powershell
# 方式一:逐个用户改
Connect-SPOService -Url https://<组织>-admin.sharepoint.com
Set-SPOSite -Identity https://<组织>-my.sharepoint.com/personal/<用户> -StorageQuota 5242   # 单位 GB
```

- **方式二:改租户默认值**(一劳永逸)—— OneDrive 管理中心 → 存储 → 把默认改成 **5120 GB** → 之后新建的子号默认就是 5T

**第三步:要 25T 的话** —— 官方规则:该用户**已用满 5TB 的 90%**(约 4.5TB)后,管理员可在管理中心/工单把上限提到 **25TB**(部分订阅还会额外分配 25TB 的 SharePoint 团队网站作为额度)。

**第四步:卖子号**(或直接卖整个全局,价格高得多)。

### 能不能自己实现:**技术上完全可以,门槛是"先有全局租户"**

| 环节 | 难度 | 说明 |
|---|---|---|
| 改 5T 配额 | **很低** | 官方命令,公开教程一堆,几分钟搞定 |
| 弄到全局租户 | **这是全部门槛** | 正规路径见第八节:VS Professional 标准订阅(¥7,760)或 ISV Success(免费,需公司) |
| 提到 25T | 低 | 先灌到 4.5TB,再改配额/开工单 |
| 长期维持 | **不可控** | 开发者版靠活跃度续期;教育版资格随时重验;租户可能被微软整体封禁 |

**结论:技术没有任何神秘之处 —— 卖家赚的是"已经有一个全局租户"的差价,不是技术。**

### 关键风险(社区反复提到)

| 风险 | 具体表现 |
|---|---|
| **管理员能看你的文件** | 租户管理员用官方 API 就能列出组织内每个成员的账号与文件;第三方 OneDrive 客户端教程甚至明说"管理员授权后可以随意查看组织中每个成员的账号,泄露了自己的文件" |
| **租户被封 = 数据全丢** | 全局被封的案例很多(教育版/开发者版被微软清理);账号封了,文件一起没 |
| **卖家可随时删你** | 你在别人的租户里,对方删号即失效 |
| **平台不保护这类交易** | 社区原话:"闲鱼**不允许卖虚拟账号**" —— 出问题维权困难 |
| **用途违规** | 开发者订阅仅限开发、教育版仅限师生;转卖/挪用属于违规,微软可撤销 |

### 建议

1. **只想要容量** → 买**正规**的 Microsoft 365 家庭版(约 ¥498/年,6TB)或国内网盘会员;比 ¥35/年的子号贵,但**数据是你的**
2. **想要"5T 且自己掌控"** → 走第八节的正规路径自己开租户(VS Professional 标准订阅 / ISV Success),自己当全局管理员
3. **不要买子号放重要数据** → 你在别人的租户里,管理员可读、可删、可被微软整体封禁
4. **任何情况下都多重备份** —— 这类容量的生命周期本来就不可控

## 十四、现在还能白嫖到「超过 10GB」的 OneDrive 吗:**能,但只有两条实用路径**

开发者订阅那条路已死(第十一节)。剩下的是**个人版**和**教育版**两条线:

### 路径一:个人版邀请扩容 —— 5GB 扩到 **15GB**(官方福利,永久)

| 项 | 内容 |
|---|---|
| 规则 | 每邀请 1 位新用户 **+0.5GB**,最多 **20 人** = **+10GB** |
| 结果 | 个人版基础 5GB → **15GB**,**永久有效** |
| 状态 | 微软**隐藏了活动入口**,但活动**仍可用** —— 直接构造邀请链接即可 |
| 链接格式 | `https://onedrive.live.com?invref=<你的cid>&invscr=90`(cid 从自己 OneDrive 的 URL 里取) |
| 操作 | 用 20 个**从未注册过 OneDrive** 的邮箱各点一次(自己用临时邮箱,或花 2–5 元找人代点) |
| 风险 | 低。属于官方福利;用临时邮箱批量点属于"薅",被判定异常时最多取消奖励,不影响账号 |

### 路径二:Office 365 A1 教育版 —— **100GB**(师生免费)

| 项 | 内容 |
|---|---|
| 额度 | **每用户 OneDrive 上限 100GB**(2024-02-01 起;此前是 1TB/5TB) |
| 资格 | 有**符合条件的学校邮箱**的教师与学生,**免费** |
| 期限 | 只要在校/在职即可用;**微软随时可能重新验证资格** |
| 备注 | 若学校用的是 **A3/A5**,学生账号的 OneDrive 通常是 **1TB 级** —— 具体问学校 IT |
| 这是免费能拿到的最大额度 | 100GB ≈ 开发者订阅(10GB)的 10 倍 |

### 其它途径(不实用,列出来备查)

| 途径 | 结果 |
|---|---|
| Microsoft Rewards 积分换礼品卡 → 抵扣 M365 订阅 | 折算约 $0.001/点,换 1TB 订阅要几十万积分,极慢 |
| Microsoft 365 免费试用 | 1TB(个人版)/ 6TB(家庭版),但**只有 1 个月**,到期自动扣费 |
| 硬件促销(三星/希捷等) | 送 100GB,但**限时**(通常 1–2 年),且要买对应设备 |
| 开发者订阅(E5/E3) | **10GB/人**,已死(见第十二节) |
| 闲鱼/淘宝买 5T 子号 | 实际已缩到 10GB,等于接盘 |

### 结论

| 想要的容量 | 现在可行的做法 |
|---|---|
| 15GB | 个人版**邀请扩容**(官方、永久、免费) |
| 100GB | **Office 365 A1 教育版**(需学校邮箱) |
| 1TB | 付费:Microsoft 365 个人版(约 ¥398/年) |
| 6TB | 付费:Microsoft 365 家庭版(约 ¥498/年,1TB x 6 人) |
| 更大 | 国内网盘会员 / 自建 NAS / 企业采购 |

**一句话:免费的天花板是「15GB(个人版邀请)」和「100GB(A1 教育版)」;再往上就得花钱。**
