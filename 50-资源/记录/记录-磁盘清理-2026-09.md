## 三、还没做(需要你决定或需要特定时机)

### 1. VHDX 离线压缩:约 47 GB(最大单项)

动态 VHDX 的宿主文件**不会**因为盘内删除而自动缩小。清理后重算的松弛量:

| 盘 | 宿主文件 | 盘内已用 | 可压缩 |
|---|---|---|---|
| D: | 362.0 GB | 343.7 GB | **18.3 GB** |
| E: | 55.1 GB | 35.6 GB | **19.5 GB** |
| F: | 20.8 GB | 11.5 GB | **9.3 GB** |

做法(需**卸载 D/E/F 几分钟**,期间不能有程序占用它们,尤其 E: 上的 Throne 代理):

```powershell
# 管理员 PowerShell;需要 Hyper-V 模块(或 Windows 的 Optimize-VHD)
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-PowerShell -All   # 只装模块
# 逐个处理:先卸载卷 -> 压缩 -> 再挂回
Dismount-VHD -Path C:\D.vhdx ; Optimize-VHD -Path C:\D.vhdx -Mode Full ; Mount-VHD -Path C:\D.vhdx
Dismount-VHD -Path C:\E.vhdx ; Optimize-VHD -Path C:\E.vhdx -Mode Full ; Mount-VHD -Path C:\E.vhdx
Dismount-VHD -Path C:\F.vhdx ; Optimize-VHD -Path C:\F.vhdx -Mode Full ; Mount-VHD -Path C:\F.vhdx
```

> 注意:在线 ReTrim(`Optimize-Volume -ReTrim`)对宿主文件**无效**,已验证过。

## 五、本次踩到的坑(值得记住)

1. **`Kill` 是 PowerShell 内置别名**(`Stop-Process`)——别名优先级**高于**同名函数,所以自定义函数 `function Kill` 会被静默忽略,脚本"跑完但什么都没删"。命名要避开内置别名(本次改用 `Purge`)。
2. **`du` 在这个环境下很慢**(MSYS 层 + VHDX 后端),全盘 `Get-ChildItem -Recurse` 更慢;定点测量 + 并行 + 每项独立超时才实用。
3. **robocopy 的字节合计行是本地化文本**(中文系统为 `字节: 1.242 g`,是**人类可读单位**),解析时要按单位换算,别当成原始字节。
4. **不要用 `Get-ChildItem $env:TEMP | Remove-Item` 清临时目录**——占用中的文件会失败(可接受),但目录本身删不掉时不要报错中断整个脚本。
5. **VHDX 是最大隐藏项**:盘内删除不等于宿主文件缩小;清理完内部后,离线 `Optimize-VHD` 才是真正回收宿主机空间的步骤。

## 六、可复用的测量片段

```powershell
# 单个目录大小(比 du / Get-ChildItem 稳)
$s = (Get-ChildItem -LiteralPath $p -Recurse -Force -File -ErrorAction SilentlyContinue |
      Measure-Object Length -Sum).Sum
'{0:N2} GB' -f ($s/1GB)

# 动态 VHDX 的松弛量(宿主文件 vs 盘内已用)
Get-Disk | Where-Object { $_.BusType -eq 'File Backed Virtual' } | ForEach-Object {
  $d = $_; $f = Get-Item -LiteralPath $d.Location -Force
  Get-Partition -DiskNumber $d.Number | ForEach-Object { Get-Volume -Partition $_ } |
    Where-Object DriveLetter | ForEach-Object {
      '{0}: file {1:N1}GB  used {2:N1}GB  compactable {3:N1}GB' -f `
        $_.DriveLetter, ($f.Length/1GB), (($_.Size-$_.SizeRemaining)/1GB), (($f.Length-($_.Size-$_.SizeRemaining))/1GB)
    }
}
```
